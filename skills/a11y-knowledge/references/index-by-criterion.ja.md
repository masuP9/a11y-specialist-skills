# 達成基準からの索引

「性質」は、その達成基準を判断するのに何が要るかの分類。自動チェックの結果だけで決まるものと、ページ全体や複数ページを見ないと決まらないものを区別する。

| 性質         | 意味                                                                                   |
| ------------ | -------------------------------------------------------------------------------------- |
| 要素         | 要素の役割・名前・属性と、周りのツリーで決まる                                           |
| ページ全体   | ページ全体の構造（ランドマーク・見出し・タイトル・lang）や、ページ全体の画像が要る         |
| 複数ページ   | 複数のページを見比べないと決まらない。[cross-page](./cross-page.ja.md) を先に読む         |
| 実測         | ブラウザで操作・計測した結果（`@a11y-skills/audit`）が要る。無ければ要確認にとどめる      |
| 目視         | 実行時の見た目や操作が要り、ツリーや実測からは決まらない                                 |
