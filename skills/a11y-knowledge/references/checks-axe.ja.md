# axe の結果の読み方

axe-core の結果（`violations` / `passes` / `incomplete` / `inapplicable`）を、達成基準の判定にどう写すか。

## 原則

- **違反（violations）は、適用条件を満たす範囲で不適合の証拠にする。** 下の「違反でも要確認にとどめる規則」と各達成基準の条件・例外を確認する。
- **合格（passes）は、その規則の検査範囲の証拠。** 下の表も達成基準全体の適合を確定する一覧ではない。残る確認は各達成基準のファイルを参照する。
- **要確認（incomplete）は要確認のまま。** 不適合にも適合にもしない。何を確かめれば決まるかを添える。
- **該当なし（inapplicable）は、その規則の対象が無かったことだけを表す。** 達成基準が NA とは限らない。

## 合格の証拠と残る確認

| axe の規則 | 達成基準 | 証拠の範囲・残る確認 |
| --- | --- | --- |
| `button-name` / `link-name` / `input-button-name` | 4.1.2 | 名前のチェック。役割、必要な状態・値、変更通知まで適合とはしない（[4.1.2-E01–E04](./criteria/4.1.2.ja.md)） |
| `image-alt` / `input-image-alt` / `role-img-alt` | 1.1.1 | 代替や名前等の実装チェック。内容の十分さ、装飾判断、対象外の内容は残る（[1.1.1-E01–E04](./criteria/1.1.1.ja.md)） |
| `target-size` | 2.5.8 | 測定対象・状態の範囲で読む。未検出の対象や例外、形状の限界を確認する（[2.5.8-E01–E04](./criteria/2.5.8.ja.md)） |

ACTの根拠は検査範囲の考え方に使う。axeが同一ルールを完全に実装していると推定しない。

**適合に数えない pass の例**（よく間違える）:

- `html-has-lang` の pass は 3.1.1 の適合にしない。lang があることと、lang が本文の言語と合っていることは別（[3.1.1](./criteria/3.1.1.ja.md)）。
- `document-title` の pass は 2.4.2 の適合にしない。タイトルがあることと、主題を表していることは別（[2.4.2](./criteria/2.4.2.ja.md)）。
- `video-caption` の pass（captions の track がある）は 1.2.2 の適合にしない。字幕の中身が音声に合っているかは見ていない（[1.2.2](./criteria/1.2.2.ja.md)）。
- `label` の pass は 3.3.2 の適合にしない。ラベルが placeholder だけでも名前は付く。

## 違反を確定にしてよい規則の例

| axe の規則         | 達成基準 | 確定する内容                                     |
| ------------------ | -------- | ------------------------------------------------ |
| `document-title`   | 2.4.2    | `<title>` が無い・空                             |
| `html-has-lang`    | 3.1.1    | `html` に lang が無い・空                        |
| `html-lang-valid`  | 3.1.1    | lang の書き方が不正                              |
| `image-alt`        | 1.1.1    | 対象画像に有効な代替・無視できる実装が無いことを確認した場合。alt欠落だけとは扱わない（[1.1.1-E02–E04](./criteria/1.1.1.ja.md)） |
| `link-in-text-block` | 1.4.1  | 文中のリンクが周りの文字と色だけで区別されている |

## 違反でも要確認にとどめる規則

| axe の規則          | 達成基準 | 理由                                                                                                     |
| ------------------- | -------- | -------------------------------------------------------------------------------------------------------- |
| `no-autoplay-audio` | 1.4.2    | `controls` 属性しか見ない。ページの別の場所に止める・音量を変える仕組みがあっても違反にするので、不適合と言い切れない |

## 要確認（incomplete）で多いもの

- `color-contrast`（1.4.3）: 背景が画像やグラデーションで比を計算できない。目視か実測で決める。
- `video-caption`（1.2.2）: captions の track が無い。焼き込み字幕がありうるので不適合にしない。
