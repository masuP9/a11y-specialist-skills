# 部品からの索引

コードを書く・レビューするときは、部品の種類からその部品に問われる達成基準を引く。部品の種類は ARIA の役割（role）でまとめている。表に無い役割は、いちばん近い種類を見る。

- 2.5.5 は AAA。既定では問わないが、ターゲットのサイズを 44px 以上にする方針のプロジェクトでは見る。
- button / link / input では、画像などの非テキストコンテンツで操作を表す場合に1.1.1も確認する。親の名前と子画像の露出を区別し、同じ欠陥は報告でまとめる（[1.1.1](./criteria/1.1.1.ja.md)）。
- この知識ベースでは `dialog` / `alertdialog` 自体を4.1.2の対象から外す。名前の欠落はベストプラクティスの改善候補として確認する。レビュー・実装では表の達成基準に加えて [4.1.2-E05と独自方針](./criteria/4.1.2.ja.md) を読む。中の操作部品は各部品の基準で評価する。
- ページ全体・複数ページの達成基準（2.4.1、2.4.2、3.1.1、3.1.2、1.4.1、1.3.3、2.3.1、3.2.3、3.2.4、3.2.6）は部品に付かない。[index-by-criterion](./index-by-criterion.ja.md) から引く。

- 文字を含む部品は、種類によらず[1.4.3](./criteria/1.4.3.ja.md)を確認する。placeholder、ホバー・フォーカス時の文字の色も含む。

- 部品・状態の視覚情報と意味のある図は [1.4.11](./criteria/1.4.11.ja.md)も確認する。フォーカスを受ける部品は [2.4.11](./criteria/2.4.11.ja.md)、AAAを評価するときは [2.4.12](./criteria/2.4.12.ja.md)・[2.4.13](./criteria/2.4.13.ja.md)も読む。

- [3.2.1](./criteria/3.2.1.ja.md)はinput以外も含め、フォーカスを受ける部品で確認する。[3.3.4](./criteria/3.3.4.ja.md)はformの外の削除ボタン等も、操作の結果が対象なら確認する。
