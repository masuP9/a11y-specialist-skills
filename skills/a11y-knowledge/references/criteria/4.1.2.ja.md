# 4.1.2 名前（name）、役割（role）及び値（value）

- 対象の部品: 操作部品すべて（button、link、入力欄、tab、menuitem、option、treeitem、gridcell、tablist、menu、tree、grid、progress）。dialog / alertdialog は対象にしない
- 要る材料: アクセシビリティツリー（名前、役割、状態）、tagName と role の組み合わせ
- 自動チェック: axe の `button-name`、`link-name`、`input-button-name`、`aria-*` 系

## 根拠

- [Understanding 4.1.2](https://www.w3.org/WAI/WCAG22/Understanding/name-role-value.html)（[日本語](https://waic.jp/translations/WCAG22/Understanding/name-role-value.html)）
  - 対象は「ユーザインタフェースコンポーネント」（利用者が操作する部品）。名前と役割がプログラムで判断でき、状態・値が判断でき、変化が支援技術に伝わること。
  - HTML 標準の部品を標準どおり使えば、ブラウザが名前・役割・状態を伝える。問題になるのは主に自作の部品（div + JavaScript）。
  - 名前の出どころは問わない（aria-label、label、title、placeholder からでも名前は名前）。
- [ARIA14: aria-label](https://www.w3.org/WAI/WCAG22/Techniques/aria/ARIA14)、[ARIA5: 状態を伝える](https://www.w3.org/WAI/WCAG22/Techniques/aria/ARIA5)、[F59: div に click だけ](https://www.w3.org/WAI/WCAG22/Techniques/failures/F59)、[F15: 標準でない部品で役割を伝えない](https://www.w3.org/WAI/WCAG22/Techniques/failures/F15)

## 線引き

- 名前は、名前があるかで判断する。出どころは問わない（placeholder や title から付いた名前も名前）。placeholder だけであることは 3.3.2 で扱い、4.1.2 の不適合の理由にしない。[解説書]
- 名前が無ければ不適合（読み上げで何の部品か分からない）。[解説書]
- HTML 標準の要素（button / a[href] / input / select / textarea）で role を変えていなければ、役割と状態はブラウザが伝えるので、名前があれば適合。[解説書]
- details の summary は開け閉めするボタンとして扱う。開いているかはブラウザが伝えるので、`aria-expanded` が無いことを理由に不適合にしない。[解説書]（ブラウザの既定の振る舞い）
- モーダル（dialog / alertdialog）は 4.1.2 の対象にしない。操作部品の入れ物で、4.1.2 の user interface component ではない。dialog の名前が無いことは 4.1.2 では不適合にしない（1.3.1 / 2.4.6 の話として見る）。[独自]
- 自作の部品（div に role を付けたもの）は、役割に応じた状態（`aria-expanded`、`aria-selected`、`aria-checked`、`aria-pressed`）が付いていて、操作で変わるかを見る。止まった画面では「変わるか」は分からないので、状態の属性が無ければ不適合、あれば要確認（操作して確かめる）。[解説書]
- リンクをボタンの代わりに使っている（href の無い a、`href="#"` で JavaScript だけ）ものは、役割が合っていないので 4.1.2 で見る（2.4.4 では問わない）。[独自]（分担）

## 作るとき

- 操作部品は標準の要素で作る（button、a[href]、input、select）。div / span に click を付けない。
- 自作の部品には、役割（role）と、役割に応じた状態（`aria-expanded` など）を付け、操作で更新する。APG のパターンに従う。
- アイコンだけのボタンには `aria-label` を付ける。
- 開閉するもの（アコーディオン、メニュー）は `<details>` / `<summary>` か、button + `aria-expanded`。
- ダイアログには `aria-labelledby` で見出しを名前にする（4.1.2 ではなく 1.3.1 / 2.4.6 のため）。

## 確かめるとき

- **確定**: axe の `button-name` / `link-name` / `input-button-name` の違反は不適合。pass は適合に数えてよい（標準の要素なら役割と状態はブラウザが伝える）。
- **残る**: 自作の部品の状態が操作で変わるか。役割が実際の振る舞いと合っているか。
- **言い切らない**: placeholder だけの名前を 4.1.2 の不適合にしない。summary に `aria-expanded` が無いことを不適合にしない。dialog の名前を 4.1.2 で問わない。
