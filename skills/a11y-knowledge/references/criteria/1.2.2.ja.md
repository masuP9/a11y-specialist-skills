# 1.2.2 キャプション（収録済み）

- 対象の部品: `<video>`（ARIA の役割は無い。埋め込み iframe の動画は別途）
- 要る材料: `<track>` の kind、`muted` / `controls` 属性、動画の中身（字幕が焼き込まれているか、音声に合っているか）
- 自動チェック: axe の `video-caption`（違反は出さない）

## 根拠

- [Understanding 1.2.2](https://www.w3.org/WAI/WCAG22/Understanding/captions-prerecorded.html)（[日本語](https://waic.jp/translations/WCAG22/Understanding/captions-prerecorded.html)）
  - 対象は「同期したメディア」（音声と映像が同期したもの）のうち収録済みのもの。音声の無い映像だけ（1.2.1 の範囲）や、映像の代替として用意されたメディアは対象外。
  - キャプションは会話だけでなく、効果音など内容の理解に要る音の情報も含む。
  - 字幕が映像に焼き込まれていても（オープンキャプション）要件は満たす。
- [G87: クローズドキャプション](https://www.w3.org/WAI/WCAG22/Techniques/general/G87)、[G93: オープンキャプション](https://www.w3.org/WAI/WCAG22/Techniques/general/G93)、[H95: track 要素](https://www.w3.org/WAI/WCAG22/Techniques/html/H95)

## 線引き

- 判定するのは「音声を含む収録済みの動画に、音声の内容を伝えるキャプションがあるか」。[解説書]
- `<track kind="captions">` があっても、それだけで適合にしない。字幕の中身が音声に合っているかは、動画を見ないと分からない。[独自]
- `<track kind="captions">` が無くても、それだけで不適合にしない。字幕が映像に焼き込まれていることがある。[解説書]（オープンキャプションは要件を満たす）
- `kind="subtitles"` は翻訳の字幕、`kind="descriptions"` は音声解説の文で、captions の代わりにならない。[解説書]
- 利用者が音声を聞けなくても読み取れる動画（`muted` で `controls` が無い、背景や飾りとして自動で流れるだけ）は対象外。[解説書]（音声が無ければ同期したメディアでない）
- 結論として、ツリーと属性だけからは適合・不適合を付けず、要確認（字幕の中身を確かめる / 焼き込みが無いか確かめる）か対象外だけにする。[独自]

## 作るとき

- 音声のある動画には `<track kind="captions" srclang="ja" label="日本語">` を付け、効果音も書く。
- 字幕を焼き込む場合は、同じ内容の書き起こしも用意すると 1.2.1 や検索にも効く。
- 背景の飾りの動画は `muted` にし、音声を入れない。
- YouTube などの埋め込みは、提供側のキャプションがあることを確かめる。自動生成の字幕は精度が足りないことが多い。

## 確かめるとき

- **確定**: 無し。axe の `video-caption` は、captions の track が無ければ要確認、あれば pass を返すが、どちらも判定にしない。
- **残る**: 字幕の中身が音声に合っているか、焼き込み字幕があるか。動画を再生して確かめる。
- **言い切らない**: track の有無だけで適合・不適合を付けない。付けてしまった判定は要確認に下げる。
