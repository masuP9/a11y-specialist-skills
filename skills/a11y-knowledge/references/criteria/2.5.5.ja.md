# 2.5.5 ターゲットのサイズ（高度）（AAA）

- 対象: ポインタ入力のターゲット（button・link等）
- 要る材料: target-size-checkの測定、実際に押せる範囲、例外の確認
- 自動チェック: target-size-check

既定のAA評価では問わない。AAAまたは44px方針を対象にしたプロジェクトで確認する。[独自: 評価範囲の方針]

- 原文確認日: 2026-11-01。WCAGは2024-12-12勧告、Understanding / Techniquesは随時更新のWCAG 2.2公開ページ。以下は引用ではなく要約。

## 根拠

### 2.5.5-E01 — 同等のターゲットは同じページで44px以上必要

- **種別・出典:** [規範 — WCAG 2.2「Target Size (Enhanced)」](https://www.w3.org/TR/2024/REC-WCAG22-20241212/#target-size-enhanced)、[Understanding —「Intent」](https://www.w3.org/WAI/WCAG22/Understanding/target-size-enhanced.html#intent)。
- **要約:** 小さいターゲットに同等のリンク・操作部品がある場合、同じページにあり44×44 CSS px以上であるか確認する。UAが決め作者が変更していないサイズ、情報伝達に必須の特定の表示も例外として確認する。
- **適用条件・限界:** 同じ機能のリンクがあるだけでは足りない。2.5.8の間隔の例外は使わない。

### 2.5.5-E02 — 文中の例外を2.5.8から流用しない

- **種別・出典:** [規範 — WCAG 2.2「Target Size (Enhanced)」](https://www.w3.org/TR/2024/REC-WCAG22-20241212/#target-size-enhanced)、[Understanding —「Intent」のInline targets](https://www.w3.org/WAI/WCAG22/Understanding/target-size-enhanced.html#intent)。
- **要約:** 例外は文またはテキストブロック内のターゲット。テキストブロック内ではない、文全体をターゲットにしたものにはサイズ要件が適用される。
- **適用条件・限界:** CSSのdisplay:inlineだけで例外にしない。2.5.8の「非ターゲットのテキストの行高で制約される」という条件をそのまま移さない。C44のTestsにもその表現があるが、本基準の例外判定は規範の文言を優先する。

### 2.5.5-E03 — 見た目ではなくポインタを受ける範囲を測る

- **種別・出典:** [規範 — WCAG 2.2「target」](https://www.w3.org/TR/2024/REC-WCAG22-20241212/#dfn-targets)、[Technique — C44「Examples」「Tests」](https://www.w3.org/WAI/WCAG22/Techniques/css/C44#tests)（Sufficient）。
- **要約:** 小さいアイコンでも、押せる範囲が44×44 CSS px以上ならサイズを満たせる。C44ではリンク自体に最小寸法とpaddingを設定する。
- **適用条件・限界:** 押せない外側の余白を寸法に足さない。CSS指定や矩形の測定だけでは、覆われた部分や特殊な形状の実際の操作範囲まで証明しない。

## 線引き

- 44px未満という測定だけで不適合を確定せず、同等・文中・UA・必須の各例外と実際の操作範囲を確認する。[根拠: 2.5.5-E01–E03]
- 既定のAA評価の問題数には混ぜず、改善候補ならAAAと明記する。AAAを評価対象にした場合は、その範囲の不適合として報告する。[独自: 評価範囲と報告方針]
- ツールの例外候補は要確認。Shadow DOM・iframe・スクリプトだけで操作を付けた要素等は検出対象外になり得る。候補外のターゲットまで適合としない。[独自: ツールとの対応。実装: [runTargetSizeCheck.ts](../../../../packages/a11y-audit/src/playwright/runTargetSizeCheck.ts)]

## 作るとき

- ボタン・アイコンは実際に押せる範囲を44×44 CSS px以上にする。見た目を小さく保つ場合は操作要素のpadding等で広げる。[根拠: 2.5.5-E03]

## 確かめるとき

- **確定:** 対象の実測寸法、実際の操作範囲、例外を照合した結果。[2.5.5-E01–E03]
- **残る:** 同じページの同等ターゲットの寸法、文・テキストブロックの文脈、UAへの変更、必須の表示。
- **言い切らない:** 2.5.8の間隔の例外による適合を2.5.5に流用しない。AAの問題数に混ぜない。[2.5.5-E01]
