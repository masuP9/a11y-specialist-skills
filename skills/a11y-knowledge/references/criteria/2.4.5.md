# 2.4.5 Multiple Ways

- Scope: Pages within a set of web pages sharing a common purpose, excluding results of and steps in a process
- Materials: The extent of the set of pages, ways to reach the target page and where they actually lead, search results, site map contents, page count, and any process
- Automated check: None. axe-core 4.14.0 has no rule tagged `wcag245`, and `@a11y-skills/audit` has no check that judges link connectivity, search, or site maps. `page-snapshot` only provides material
- Sources checked: 2026-11-05. WCAG: Recommendation of 2024-12-12. Understanding updated 2026-04-05; G63, G64, G125, and G185 updated 2025-07-15; G126 updated 2026-03-09; G161 updated 2025-10-15 (living published pages). The following are summaries, not quotations.

## Evidence

### 2.4.5-E01 — Determine the set of pages and the targets

- **Type / source:** [Normative — Multiple Ways](https://www.w3.org/TR/2024/REC-WCAG22-20241212/#multiple-ways), [Term — set of web pages](https://www.w3.org/TR/2024/REC-WCAG22-20241212/#dfn-set-of-web-pages), [Term — web page](https://www.w3.org/TR/2024/REC-WCAG22-20241212/#dfn-web-page-s).
- **Summary:** A set is a collection of pages sharing a common purpose, created by the same author, group, or organization. Examples include checkout pages not being part of the set of product pages, and a blog on a sub-domain with different navigation and authors. An application that switches inbox and contacts without changing the URI is one web page.
- **Conditions / limits:** The domain alone does not determine the extent of the set. Decide from navigation, authorship, and purpose.

### 2.4.5-E02 — Exclude results of and steps in a process

- **Type / source:** [Normative — Multiple Ways](https://www.w3.org/TR/2024/REC-WCAG22-20241212/#multiple-ways), [Term — process](https://www.w3.org/TR/2024/REC-WCAG22-20241212/#dfn-processes), [Understanding — Examples](https://www.w3.org/WAI/WCAG22/Understanding/multiple-ways.html#examples).
- **Summary:** Pages that are the result of or a step in a process are out of scope. A funds transfer confirmation and search engine results are examples.
- **Conditions / limits:** A process is a series of user actions where each is required to complete an activity. This does not exclude every page related to a process.

### 2.4.5-E03 — Count the ways

- **Type / source:** [Understanding — Sufficient Techniques](https://www.w3.org/WAI/WCAG22/Understanding/multiple-ways.html#sufficient), [Understanding — Examples](https://www.w3.org/WAI/WCAG22/Understanding/multiple-ways.html#examples).
- **Summary:** Two or more of G125 (links to related pages), G64 (table of contents), G63 (site map), G161 (search), G126 (a list of links to all other pages), and G185 (links to all pages from the home page) are sufficient. Examples include search with a category list box, and previous/next links with a list of links to all pages.
- **Conditions / limits:** The kinds of ways are not limited to this list. Do not fail for not using a Technique alone.

### 2.4.5-E04 — Home pages of small sites

- **Type / source:** [Understanding — Intent](https://www.w3.org/WAI/WCAG22/Understanding/multiple-ways.html#intent), [G185 "Description"](https://www.w3.org/WAI/WCAG22/Techniques/general/G185#description), [G185 "Tests"](https://www.w3.org/WAI/WCAG22/Techniques/general/G185#tests).
- **Summary:** On a three or four page site with all pages linked from the home page, links from and to the home page may be sufficient, with the home page's links also serving as a site map. G185 describes the home page as two mechanisms in one.
- **Conditions / limits:** G185 itself is listed as "Sufficient when combined with other techniques", in line with "two or more" in the Understanding list. Sufficiency on its own comes from Intent and the G185 description, and no upper page limit is defined.

### 2.4.5-E05 — Confirm each way works

- **Type / source:** [G63 "Description"](https://www.w3.org/WAI/WCAG22/Techniques/general/G63#description), [G63 "Tests"](https://www.w3.org/WAI/WCAG22/Techniques/general/G63#tests), [G161 "Tests"](https://www.w3.org/WAI/WCAG22/Techniques/general/G161#tests), [G64 "Tests"](https://www.w3.org/WAI/WCAG22/Techniques/general/G64#tests), [G126 "Description"](https://www.w3.org/WAI/WCAG22/Techniques/general/G126#description), [G126 "Tests"](https://www.w3.org/WAI/WCAG22/Techniques/general/G126#tests), [G125 "Tests"](https://www.w3.org/WAI/WCAG22/Techniques/general/G125#tests).
- **Summary:** A site map must link to all sections, match the site's organization, have no broken links, be linked back from its targets, and lead to every page. Search must be usable from a form or link on the page, and searching a term in the set must lead to the matching page or a list of them. A table of contents must match the document's sections and order and link to the right sections. G126 works for small sets, with every page carrying the list.
- **Conditions / limits:** G126's list of links needs a bypass mechanism under [2.4.1](./2.4.1.md). G125 checks that links lead to related information, not that all pages are covered.

## Judgment lines

- Pass if the target page can be reached in two or more ways. Fail if a page has only one way to reach it. Ways outside the Technique list count if they actually reach the page. [Evidence: 2.4.5-E01, E03]
- Count only ways that actually reach the target page. Breadcrumbs that lead only to parents do not count for lower-level pages. [Author policy: counts ways per target page. Evidence: 2.4.5-E03, E05]
- The same list of links in both the header and footer counts as one way. [Author policy: it does not add a choice of how to find content. Evidence: 2.4.5-E03]
- Do not count users finding a page through an external search engine. Count site search the site provides, even if built on an external search service. [Author policy: count ways provided by the set. Evidence: 2.4.5-E03, E05]
- Steps in and results of a process are out of scope. Check that the page starting a process (such as an application form's entrance) is reachable as a regular page. [Author policy: pages before the process starts. Evidence: 2.4.5-E02]
- On a three or four page site, Pass if all pages are linked from the home page and each page links back to it. For five or more pages, check for a second way. [Author policy: adopts Intent and the G185 description within the page count Understanding gives. Evidence: 2.4.5-E04]
- If the set has only one page, treat it as out of scope (NA), since there are no other pages. [Author policy: reads this as a criterion for locating pages within a set. Evidence: 2.4.5-E01]

## Judgment examples

- **Pass:** Every page's header has navigation and site search, and the target page can be found from both. [Evidence: 2.4.5-E03, E05]
- **Pass:** On a four page site, the home page links to the other three pages, and each page links back to the home page. [Author policy. Evidence: 2.4.5-E04]
- **Pass:** A five page hair salon site has previous/next links and a list of links to all pages. [Evidence: 2.4.5-E03]
- **Out of scope:** A funds transfer confirmation, search results, and step 2 of checkout. [Evidence: 2.4.5-E02]
- **Fail:** A thirty page site has only the same navigation in its header and footer, with no search or site map. [Author policy: counting the same list. Evidence: 2.4.5-E03]
- **Fail:** The site has a site map and search, but the target page can be found only by search, with no link from the site map or navigation. [Evidence: 2.4.5-E05]
- **Needs review:** A campaign page has no links from anywhere on the site. Confirm from its purpose, author, and navigation whether it belongs to the set of pages. If it does, count the ways to reach it. [Author policy: inspection example. Evidence: 2.4.5-E01]

## When building

- In addition to navigation, make site search or a site map available from every page. [Evidence: 2.4.5-E03, E05]
- Update the site map as the site changes. [Evidence: 2.4.5-E05]

## When checking

- **Implementation confirmed:** `page-snapshot` provides search form, navigation, and link material but does not confirm reachability. Material from audited pages alone does not show ways to reach a page from pages outside the audit scope.
- **Settled:** The result of actually using each way to reach each target page. Try search with terms from the target page.
- **Remaining:** Coverage of all pages. State the sampled scope. Check pages that exist only after login in a logged-in environment.
- **Do not assert:** Do not Pass only because a search form or a link to a site map exists. Do not claim conformance for pages outside the sample. Including the site map page in the audit targets is recommended.
