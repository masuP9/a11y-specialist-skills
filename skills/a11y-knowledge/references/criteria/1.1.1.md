# 1.1.1 Non-text Content

- Components in scope: image (img, figure). For image-only buttons and links, judge the image inside them
- Inputs needed: accessibility tree (name, alt attribute, parent's name), image content (screenshot)
- Automated checks: axe `image-alt` / `input-image-alt` / `role-img-alt`

## Rationale

- [Understanding 1.1.1](https://www.w3.org/WAI/WCAG22/Understanding/non-text-content.html) ([Japanese translation](https://waic.jp/translations/WCAG22/Understanding/non-text-content.html))
  - A text alternative "serves the equivalent purpose". It need not describe the image's appearance; it should express the role the image plays in that place (the destination for a link, the action for a button).
  - Pure decoration, visual formatting only, and content not presented to users may be implemented so assistive technology can ignore it (`alt=""`).
  - Whether a text alternative is "sufficient" depends on context. Some images need only a short name; others, like charts, need a long description.
- [H37: alt attribute on img](https://www.w3.org/WAI/WCAG22/Techniques/html/H37), [H67: empty alt for decorative images](https://www.w3.org/WAI/WCAG22/Techniques/html/H67), [ARIA6: aria-label](https://www.w3.org/WAI/WCAG22/Techniques/aria/ARIA6)

## Judgment lines

- A button or link whose only content is the image is conformant if the button or link itself has a name (aria-label, title, visually hidden text, and so on), even if the inner image has no alt. The parent's name serves as the text alternative. [Understanding] (text that serves the equivalent purpose is enough)
- An image-only button with no name, or with a name that does not express the action ("button", "image", "icon", a file name), is non-conformant. [Understanding]
- An image with no alt attribute at all is not necessarily non-conformant, but is not marked conformant. If it can be read as carrying information (inside a link or button, a logo inside a heading, a wide main image, an image with no equivalent text nearby), it is non-conformant. If it could also be read as decorative, needs review (decide by looking at the image). [Our interpretation]
- `alt=""` is a declaration of decoration. If decorative, conformant. If the image can be read as carrying information (text inside the image, a logo, a banner with text), non-conformant. [Understanding]
- If there is text inside the image, do not judge it decorative. [Our interpretation] (from the mistake of judging a logo decorative by looking at it and marking it conformant)
- A wide main image or a carousel slide is not judged decorative even if it has no text (non-conformant if it has no alt attribute). [Our interpretation] (from the mistake of looking at a text-free main image and treating it as decoration)
- A text-free photo or illustration that only shows the same thing as the text right next to it is not judged as carrying information, even when its content is visible (conformant with `alt=""`). [Our interpretation] (from the mistake of marking a photo next to a card heading non-conformant as "carries information but alt is empty")
- Images with `aria-hidden="true"` are out of scope in principle (ignored by screen readers). However, when there is a strong inference that it will later be shown and read (carousel slides: images of the same size lined up horizontally, outside the viewport, with switching buttons like "next slide"), judge it in its unhidden state. [Our interpretation]
- A name that does not express the image's content ("image", "photo", a file name, "spacer") is non-conformant. [Understanding]
- When the name is a word that expresses the content (a character name, a person's name, a product name), do not mark non-conformant on the guess that "the description may be insufficient". Mark non-conformant only when the surrounding information makes the shortfall clear (a chart or a text-heavy notice image with only a short name); if merely doubtful, needs review. [Our interpretation]
- For buttons and links, 1.1.1 is not asked of the button or link itself but checked on the image inside it (that is why the component index has no 1.1.1 for button or link). Asking it on both counts the same defect twice. [Our interpretation]
- `<input type="image">` has no image element inside it: the button itself is the image. Judge whether its alt (the button's name) expresses the action, as with an image-only button. axe `input-image-alt` catches a missing name, but not a name that does not express the action ("btn_submit.gif"). [Understanding]
- Text input fields (textbox, searchbox, spinbutton) and checkboxes are not non-text content, so 1.1.1 is not asked of them. Do not apply the "Controls, Input" exception of 1.1.1 to an input field with no name and mark it non-conformant: that exception is for non-text content that is itself a control. The field's name is checked under 4.1.2, and its association with a visible label under 1.3.1. [Understanding]

## When building

- For image-only buttons and links, give the name of the action or destination, not the image, via `aria-label` or visually hidden text. Set the inner `<img>` to `alt=""`.
- For informative images, write in alt the role the image plays in that place. For a logo, the organization name; for a chart, the key point (if long, write it in the body text or caption and have alt point to it).
- For decorative images, `alt=""` (or a CSS background). Do not omit `alt`. An omission cannot be distinguished from "forgot".
- Give alt to images shown later, such as in a carousel. The alt is still needed while hidden with `aria-hidden`.
- Put text inside the image into alt (whether images of text are acceptable is 1.4.5).

## When checking

- **Settled**: violations of axe `image-alt` / `input-image-alt` / `role-img-alt` (an `<img>` with no alt attribute, and so on) are non-conformant. Passes on these may be counted as conformant (a name exists).
- **Remains**: whether the name expresses the content, and whether an `alt=""` image is really decorative. Cannot be decided without looking at the image.
- **Do not assert**: do not mark an image with no alt attribute non-conformant or conformant without looking at it (needs review, as in the judgment lines above). Do not mark an image that has a name non-conformant because "the description may be insufficient".
