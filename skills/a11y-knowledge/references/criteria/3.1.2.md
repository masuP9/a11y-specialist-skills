# 3.1.2 Language of Parts

- Scope: Words, phrases, and passages in a language different from the surrounding text (including attribute values)
- Materials: The language of content and attribute values, the `lang` an element inherits, the language of the surrounding text, and whether a phrase falls under an exception
- Automated check: axe `valid-lang` examines only the language tag value. It does not detect missing declarations or mismatches with content
- Sources checked: 2026-11-05. WCAG: Recommendation of 2024-12-12. Understanding updated 2026-07-12 and H58 updated 2025-09-25 (living published pages). ACT de46e4 is approved, version of 2023-12-20; off6ek is Proposed. The following are summaries, not quotations.

## Evidence

### 3.1.2-E01 — Confirm scope and inherited language

- **Type / source:** [Normative — Language of Parts](https://www.w3.org/TR/2024/REC-WCAG22-20241212/#language-of-parts), [Understanding — Intent](https://www.w3.org/WAI/WCAG22/Understanding/language-of-parts.html#intent), [H58 "Tests"](https://www.w3.org/WAI/WCAG22/Techniques/html/H58#tests) (Sufficient).
- **Summary:** A single word can be in scope. Parts with no other language specified take the page's default language, so a single-language document is determined by that default. H58 checks that each element's content language matches its inherited language, and that `lang` values conform to BCP 47 and match the content.
- **Conditions / limits:** H58 is an HTML method; check PDF19 and others for PDF. H58 treats the primary language code as important and subtags such as region as optional.

### 3.1.2-E02 — Compare the four exceptions with the surrounding text

- **Type / source:** [Normative — Language of Parts](https://www.w3.org/TR/2024/REC-WCAG22-20241212/#language-of-parts), [Understanding — Intent](https://www.w3.org/WAI/WCAG22/Understanding/language-of-parts.html#intent), [Understanding — "Podcast" example](https://www.w3.org/WAI/WCAG22/Understanding/language-of-parts.html#podcast-used-in-a-french-sentence).
- **Summary:** The exceptions are proper names, technical terms, words of indeterminate language, and words or phrases that have become part of the vernacular of the immediately surrounding text. Examples include Albert Camus, Homo sapiens, hertz, rendezvous in English, and podcast in French.
- **Conditions / limits:** The comparison is with the immediately surrounding text, not the page's primary language. Marking these words is a best practice, not a requirement. Understanding gives no specific example of "words of indeterminate language".

### 3.1.2-E03 — Treat a single word as the surrounding language by default, and use pronunciation when in doubt

- **Type / source:** [Understanding — Intent](https://www.w3.org/WAI/WCAG22/Understanding/language-of-parts.html#intent).
- **Summary:** A single word that appears to be in another language is treated as part of the surrounding language unless a change of language was clearly intended. In doubt, consider whether it would be pronounced the same (except for accent or intonation) in the surrounding language.
- **Conditions / limits:** This does not make a whole phrase an established term. Speech synthesis quality varies by product, so do not use one product's speech output as the criterion.

### 3.1.2-E04 — Examples of marking phrases in another language

- **Type / source:** [Understanding — "A German phrase" example](https://www.w3.org/WAI/WCAG22/Understanding/language-of-parts.html#a-german-phrase-in-an-english-sentence), [Understanding — "Alternative language links" example](https://www.w3.org/WAI/WCAG22/Understanding/language-of-parts.html#alternative-language-links), [Understanding — attribute value example](https://www.w3.org/WAI/WCAG22/Understanding/language-of-parts.html#the-elements-content-and-attribute-values-are-in-different-languages).
- **Summary:** A German phrase in an English sentence is marked. Language switcher links such as "Deutsch" and "Français" are marked with their own languages. When content and attribute values differ in language, `lang` goes on an element around the content to keep it separate from the attribute value.
- **Conditions / limits:** These are examples and do not limit where `lang` can go.

### 3.1.2-E05 — Check the code, not speech output

- **Type / source:** [Understanding — note in Intent](https://www.w3.org/WAI/WCAG22/Understanding/language-of-parts.html#intent).
- **Summary:** Accessible names are strings with no language information, so correctly marked content may not switch language in contexts such as a list of links. This is a limitation of user agents and assistive technologies and does not fail this criterion. Evaluators must not rely on speech output alone and must verify the code.
- **Conditions / limits:** This does not prohibit checking speech output. Correct speech output is not grounds for a Pass either.

### 3.1.2-E06 — Separate the scope of ACT and axe

- **Type / source:** [ACT de46e4 "Accessibility Requirements Mapping"](https://www.w3.org/WAI/standards-guidelines/act/rules/de46e4/#accessibility-requirements-mapping), [ACT de46e4 "Assumptions"](https://www.w3.org/WAI/standards-guidelines/act/rules/de46e4/#assumptions) (approved), [ACT off6ek](https://www.w3.org/WAI/standards-guidelines/act/rules/off6ek/proposed/) (Proposed; not treated as a current approved rule).
- **Summary:** de46e4 checks that the `lang` of an element passing on text has a known primary language. Failed means not satisfied; passed needs further testing. Where `lang` indicates a programming language, the content may conform despite failing. Three-letter language codes and similar are assumed not to be known primary languages.
- **Conditions / limits:** de46e4 does not decide where `lang` should be used. off6ek is referenced from Understanding and H58 but is Proposed, so do not use it as grounds for a settled verdict.

## Judgment lines

- Fail where words or passages in a language different from their surroundings have no correct language declaration. Do not flag proper names, technical terms, words of indeterminate language, or words and phrases established in the surrounding text. [Evidence: 3.1.2-E01–E02]
- Fail where the primary language of a declared `lang` differs from the content or is invalid. Do not fail on differences in region or script subtags alone. [Evidence: 3.1.2-E01, E06. Subtags are [Author policy]: judge by primary language, as in [3.1.1](./3.1.1.md)]
- Compare exceptions with the immediately surrounding text. A Japanese phrase inside an English quotation with `lang="en"` needs a declaration even if the page's primary language is Japanese. [Evidence: 3.1.2-E02]
- Treat a single English word in Japanese text (such as `Menu`, `NEWS`, or `Login`) as part of the Japanese and do not fail it. For words in doubt, judge by whether they would be pronounced the same when read as Japanese. [Author policy: applies the E03 default to labels on Japanese pages. Evidence: 3.1.2-E03]
- Keep phrases of two or more words (such as `Read more` or `Contact us`) in scope unless they are proper names or established phrases. [Author policy: E03 is not extended to phrases. Evidence: 3.1.2-E02–E03]
- Keep a language name in a language switcher link written in a different language from its surroundings (such as `English` on a Japanese page) in scope, even as a single word. [Author policy: a word with a clearly intended language change, applying the Understanding example ahead of the single-word default. Evidence: 3.1.2-E03–E04]
- Check `alt`, `aria-label`, `title`, and `placeholder` values by the same rules as content. [Evidence: 3.1.2-E04. Extending to these attributes is [Author policy]: the Understanding example covers only title]
- Treat code snippets as technical terms and do not require a natural-language `lang`. Keep explanatory prose in another language in scope. [Author policy: no example in the source. Evidence: 3.1.2-E02, E06]
- Report a wrong page default language under [3.1.1](./3.1.1.md), and do not add a 3.1.2 report for that alone. [Author policy: report one defect once. Evidence: 3.1.2-E01]

## Judgment examples

- **Pass:** A German phrase in an English sentence has `lang="de"`. [Evidence: 3.1.2-E04]
- **Pass:** Japanese text contains `Apple Pay` or `HTML`, which are a proper name and a technical term. [Evidence: 3.1.2-E02]
- **Pass:** Navigation on a Japanese page has the single English word `NEWS`. `lang` can be recommended as an improvement. [Author policy. Evidence: 3.1.2-E02–E03]
- **Pass:** A link contains English with `lang`, and a list of links reads it in a Japanese voice. [Evidence: 3.1.2-E05]
- **Fail:** A Japanese page has an English paragraph with no `lang`. [Evidence: 3.1.2-E01]
- **Fail:** A button on a Japanese page says `Read more` with no `lang`. [Author policy: phrase treatment. Evidence: 3.1.2-E01, E03]
- **Fail:** A language switcher link `English` on a Japanese page has no `lang`. [Author policy: language name treatment. Evidence: 3.1.2-E03–E04]
- **Fail:** An English paragraph has `lang="ja"`. Fail even when axe passes. [Evidence: 3.1.2-E01, E06]
- **Needs review:** It is unclear whether an English tagline is a registered brand name. Check brand materials, and judge it as a phrase if it is not a proper name. [Author policy: inspection example. Evidence: 3.1.2-E02]

## When building

- Put `lang` on an element around the phrase in another language, separately from the page's `lang`. Use separate elements when content and attribute values differ in language. [Evidence: 3.1.2-E01, E04]
- Recommend `lang` on excepted words too, to help pronunciation, especially for words in another writing system. This is not a requirement. [Evidence: 3.1.2-E02]

## When checking

- **Implementation confirmed:** axe-core 4.14.0 `valid-lang` (`wcag312`) targets non-`html` elements with `lang` or `xml:lang`, validates the base language tag, and skips elements with no text. Three-letter codes such as `jpn` are invalid. The `page-snapshot` `lang` is only the `html` value, and the aria snapshot does not output per-element `lang`, so check the DOM.
- **Settled:** `valid-lang` violations where `lang` indicates a natural language. The result of comparing content with DOM `lang`.
- **Remaining:** Missing declarations and mismatches with content are not detected automatically. Do not treat a `valid-lang` pass as conformance to the whole SC.
- **Do not assert:** Do not map violations to Fail where `lang` indicates a programming language. Do not fail on speech output differences alone.
