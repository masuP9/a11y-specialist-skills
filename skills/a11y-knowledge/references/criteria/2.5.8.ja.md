# 2.5.8 ターゲットのサイズ（最低限）

- 対象の部品: ポインターで操作する部品（button、link、checkbox、slider など）
- 要る材料: 押せる範囲と周辺の実測、文脈、同じ機能の別操作、表示状態
- 自動チェック: target-size-check、axe の `target-size`
- 原文確認日: 2026-11-01。WCAG は 2024-12-12 勧告、Understanding / Techniques は WCAG 2.2 公開ページ（随時更新）。以下は引用ではなく要約。

## 根拠

### 2.5.8-E01 — サイズ不足だけでは不適合を確定できない

- **種別・出典:** [規範 — WCAG 2.2「Target Size (Minimum)」](https://www.w3.org/TR/2024/REC-WCAG22-20241212/#target-size-minimum)、例外と注記。
- **要約:** 小さいターゲットには、間隔、同一ページの同機能の操作、文中、UA が決めた未変更のサイズ、必須の表示という例外がある。
- **適用条件・限界:** 例外の存在を推測するだけでは適合にできない。逆に、測定ツールが例外を検出しなかったことだけでは全例外を除外できない。スライダーなど位置で値を選ぶ領域を、値ごとの小さいターゲットに分割しない。

### 2.5.8-E02 — 間隔は円とターゲットの両方で確かめる

- **種別・出典:** [Technique — C42「Tests」](https://www.w3.org/WAI/WCAG22/Techniques/css/C42#tests)（Sufficient）。
- **要約:** 小さいターゲットの bounding box 中心に直径24 CSS pxの円を置き、他のターゲットおよび他の小さいターゲットの円との交差を確認する。
- **適用条件・限界:** 他の例外に該当するものを除いて確認する。C42 はコンテナ内の配置による間隔の確保であり、コンテナが24pxあることと実際に押せる範囲が24pxあることを混同しない。このCSS手法自体は必須ではない。

### 2.5.8-E03 — 文中の例外は文脈による

- **種別・出典:** [Understanding —「Exceptions」](https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum.html#exceptions)。
- **要約:** 文の中にある、またはターゲットではない文字の行高によってサイズが制約される場合に文中の例外を使える。
- **適用条件・限界:** `display: inline`、親のタグ、リンクの名前だけでは確定しない。リンクだけが並ぶナビゲーションも、単にインライン表示だからという理由では免除しない。

### 2.5.8-E04 — 見た目の矩形と押せる領域を区別する

- **種別・出典:** [Understanding —「Size requirement」](https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum.html#size-requirement)。
- **要約:** サイズの確認では、押せる領域内にページの軸に沿った24 × 24 CSS pxの正方形が収まるかを見る。覆いが出た状態では、覆われた背後と新たに出た操作部品を区別する。
- **適用条件・限界:** 外接矩形だけの測定では非矩形・クリップされた領域を確定できない。初期表示だけで、開いたメニューやダイアログ内の対象まで確認済みにしない。

## 線引き

- サイズ不足と全例外の不成立が確認できた対象を不適合にする。間隔が不十分でも、別の例外が成立すれば不適合にしない。[根拠: 2.5.8-E01, 2.5.8-E02]
- 文中か不明なら要確認。「否定する根拠がない」だけでは文中の例外を認めない。[根拠: 2.5.8-E03]
- 間隔の条件を満たす対象は、その例外で判定できる。小さいという理由だけで要確認に戻さない。ただし近隣ターゲットの検出漏れがあれば残す。[根拠: 2.5.8-E01, 2.5.8-E02]
- 実測対象・形状・状態の範囲を記録し、対象単位の結果をページ全体の適合に広げない。[独自: 確認範囲の記録。根拠: 2.5.8-E04]

## 作るとき

- 押せる領域を padding などで広げる。見た目のアイコンや外側のコンテナのサイズだけを増やして済ませない。[2.5.8-E02, 2.5.8-E04]
- 小さいリンクを並べる場合は、円による確認を満たす間隔を確保する。文中のリンクは文脈を確かめて例外を使う。[2.5.8-E02, 2.5.8-E03]

## 確かめるとき

- **確定:** サイズ・間隔と例外の確認を終えた対象について判定する。[2.5.8-E01–E04]
- **残る:** `target-size-check` の `exceptionAssessment: "possible"` / `"not-assessed"` は要確認。`"verified"` は検出範囲内の間隔の確認であり、隣の対象の検出漏れ、iframe、shadow DOM、非矩形や別の表示状態まで保証しない。[独自: ツールとの対応。実装: [runTargetSizeCheck.ts](../../../../packages/a11y-audit/src/playwright/runTargetSizeCheck.ts)、[types.ts](../../../../packages/a11y-audit/src/types.ts)]
- **言い切らない:** `intersections` は間隔の例外を否定する材料であって、他の例外を否定しない。axe の pass も、測定・検出範囲を越えて達成基準全体の適合にしない。[2.5.8-E01, 2.5.8-E04]
