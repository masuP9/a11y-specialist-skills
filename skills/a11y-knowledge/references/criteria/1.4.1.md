# 1.4.1 Use of Color

- Scope: whole page (look for places that convey information by color). Not attached to components
- Inputs needed: image of the whole page (whether cues other than color are visible), element styles (weight, size, underline, border, lightness)
- Automated checks: axe `link-in-text-block` (links in running text)

## Rationale

- [Understanding 1.4.1](https://www.w3.org/WAI/WCAG22/Understanding/use-of-color.html) ([Japanese translation](https://waic.jp/translations/WCAG22/Understanding/use-of-color.html))
  - Using color is not prohibited. Information, actions, responses, and distinctions must not be conveyed by color "alone".
  - A difference in relative luminance (lightness) counts as a "distinction other than color". The note in Understanding: even if the hues differ, a lightness ratio of 3:1 or more does not rely on color perception.
  - The contrast ratio itself is the range of 1.4.3 / 1.4.11.
- [G14: cues other than color](https://www.w3.org/WAI/WCAG22/Techniques/general/G14), [G182: also showing color differences by lightness differences](https://www.w3.org/WAI/WCAG22/Techniques/general/G182), [G183: 3:1 contrast and an additional cue](https://www.w3.org/WAI/WCAG22/Techniques/general/G183), [F13: conveying by image color alone](https://www.w3.org/WAI/WCAG22/Techniques/failures/F13), [F73: indicating links in text by color alone](https://www.w3.org/WAI/WCAG22/Techniques/failures/F73), [F81: indicating errors by color alone](https://www.w3.org/WAI/WCAG22/Techniques/failures/F81)

## Judgment lines

- What to look for: places that convey information by a difference in color: chart series and legends, required fields or input errors shown with red text or a red border, navigation or tabs showing the selected item or current location by color, status shown by a colored dot or badge, and notes that explain by color such as "items in red are ...". [Understanding]
- If the same information can be understood from a cue other than color (text, symbol, shape, pattern, line style, underline, bold, border, icon shape, position), conformant. Cues are limited to what is visible on screen. Text that exists only in the accessibility tree (visually hidden text, `aria-current`) does not count as a visual cue. [Understanding]
- Even if each item has a different color, do not list it if the visible name or text on that item conveys the same information (buttons with a different color per type and the name written too, like Info / Success / Warning / Error. The color supplements the name). [Our interpretation] (from the pattern of misjudgments)
- List something as selected or current location only when, among items of the same appearance, only one (or some) differs in color. Do not infer the selected item from a row where every color differs. `aria-pressed` / `aria-selected` / `aria-current` do not count as cues, but are used to tell whether the component has a selection state. [Our interpretation]
- Lightness difference: for things where it is enough to tell which one differs from the others (selected / current location, a single differing item), conformant if the foreground and background are swapped or the lightness ratio is 3:1 or more, as with white and a dark color. Colors of similar lightness (red and green of about the same lightness) or borderline differences are non-conformant. [Understanding] (the note in Understanding)
- Things whose meaning cannot be understood without knowing which color it is, like "red is required, blue is optional" or "a green dot is online, a red dot is offline", are non-conformant even with a lightness difference. [Our interpretation] (a lightness difference only works for "which one differs")
- Even if the meaning of a cue is explained at a distant place on the page, count it as a cue if that explanation is visible (the note "* is required" and "Address *" far away). [Our interpretation]
- When fields or items of the same appearance (red border, red text) are lined up, check the cue for each one. An error message or symbol serves only as a cue for the field it is attached to (if only the neighboring field has an error message, the field without one is non-conformant). [Our interpretation] (from the pattern of misses)
- A note that explains by color alone, like "items in red are required", makes both the note itself and the items using that color non-conformant. [Understanding]
- A chart is non-conformant if series and legend correspond by color alone. Conformant if there are line styles, marker shapes, names attached directly to the series, or a table of the same values right beside it. [Understanding] (G111 / G14)
- Do not list: links in running text distinguished by color alone (leave to axe `link-in-text-block`), colors with no meaning (heading backgrounds, brand colors, decoration), color swatches that convey the color itself, colors inside photos or illustrations, contrast ratio (1.4.3 / 1.4.11), colors that change only on hover or focus. [Our interpretation] (division)
- Differences that count as cues when checking by style: a `font-weight` difference of 200 or more (400 to 600. A difference of 100 is hard to tell apart), a difference in `font-style`, a font size ratio of 1.125 or more, a difference in `text-decoration-line`, a difference in the thickness of the visible sides of a border, a lightness ratio of 3:1 or more in background or text color. A difference in border color alone does not count. [Our interpretation]

## When building

- Where color indicates status or category, always add one more cue: "*" or the word "required" for required fields, a message and icon for errors, bold / underline / border for the selected item, line style / marker / direct labels for chart series.
- Do not write notes like "red text is required". Indicate with a symbol or text instead of color, and explain that meaning in the note.
- Keep underlines on links in running text. Do not make them distinguishable by color alone.
- If distinguishing by lightness difference, make it 3:1 or more and use it only for "which one differs". Do not substitute lightness for the meaning of a color (red = danger).

## When checking

- **Settled**: violations of axe `link-in-text-block` are non-conformant (links in running text distinguished by color alone).
- **Remains**: look for places matching the judgment lines above by viewing the image of the whole page. For places that look like color alone, re-check for cues by style (weight, underline, border, lightness).
- **Do not assert**: do not mark color coding non-conformant when the name or text conveys the same information. Do not treat contrast ratio problems as 1.4.1. Do not judge colors that change on hover from the image.
