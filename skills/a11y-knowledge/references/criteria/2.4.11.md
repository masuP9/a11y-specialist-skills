# 2.4.11 Focus Not Obscured (Minimum)

- Scope: whole page
- Inputs needed: measurement (`obscured` from focus-indicator-check in `@a11y-skills/audit`. Overlap with fixed-position elements)
- Automated checks: focus-indicator-check (`focus-not-obscured`)

## Rationale

- [Understanding 2.4.11](https://www.w3.org/WAI/WCAG22/Understanding/focus-not-obscured-minimum.html) ([Japanese translation](https://waic.jp/translations/WCAG22/Understanding/focus-not-obscured-minimum.html))
  - The focused element must not be entirely hidden by author-created content (a fixed header, a sticky footer, a cookie banner). If part of it is visible, the minimum is satisfied (being fully visible is 2.4.12, AAA).
  - Being hidden by something the user opened (a menu, a dialog) is an exception. Being hidden by content the user can move (close) is also an exception.
- [C43: using scroll margin to avoid obscuring](https://www.w3.org/WAI/WCAG22/Techniques/css/C43), [F110: hidden by a fixed element](https://www.w3.org/WAI/WCAG22/Techniques/failures/F110)

## Judgment lines

- When the focused element is entirely hidden (99% or more) by a fixed-position (fixed / sticky) element, non-conformant unless the overlapping thing can be read as something the user opened (a menu or dialog). [Understanding]
- Partially hidden elements are conformant under 2.4.11 (the range of 2.4.12). [Understanding]
- Conformant if there are zero entirely hidden elements, the measurement finished to the end, there is at least one operable element, and zero elements were skipped. Add "only overlap with fixed-position elements was examined". [Our interpretation]
- Do not mark non-conformant when there are no entirely hidden elements. Even if the measurement stopped partway, keep the non-conformances that were found. [Our interpretation]

## When building

- If there is a fixed header or footer, use `scroll-padding-top` / `scroll-padding-bottom` (or `scroll-margin` on the element) so the focused element does not go under the fixed part.
- Keep cookie banners to a part of the screen, so the area where focus can be hidden is small.
- Make sticky banners closable (if the user can move it, it becomes an exception).

## When checking

- **Settled**: if there are `fullyObscured` elements and the overlapping thing is fixed-position content, non-conformant.
- **Remains**: check whether the overlapping thing is something the user opened.
- **Do not assert**: do not mark partially hidden elements non-conformant under 2.4.11. Do not mark conformant from a measurement that stopped partway.
