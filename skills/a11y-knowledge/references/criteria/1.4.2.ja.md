# 1.4.2 音声の制御

- 対象: ページ全体（`<audio>` / `<video>` の自動再生）
- 要る材料: 実測（`@a11y-skills/audit` の auto-play-detection の `audio`）
- 自動チェック: auto-play-detection、axe の `no-autoplay-audio`

## 根拠

- [Understanding 1.4.2](https://www.w3.org/WAI/WCAG22/Understanding/audio-control.html)（[日本語](https://waic.jp/translations/WCAG22/Understanding/audio-control.html)）
  - 自動で 3 秒を超えて鳴る音声には、一時停止・停止の手段か、システム全体の音量とは独立した音量の調整手段が要る。
  - 手段は「ページの先頭近く」にあればよく、メディア自体のコントロールでなくてもよい。
  - 3 秒以内なら対象外。利用者の操作で鳴り始めるものも対象外。
- [G60: 3 秒以内](https://www.w3.org/WAI/WCAG22/Techniques/general/G60)、[G170: 止める手段をページの先頭に](https://www.w3.org/WAI/WCAG22/Techniques/general/G170)、[F23: 3 秒を超えて鳴り、止める手段が無い](https://www.w3.org/WAI/WCAG22/Techniques/failures/F23)

## 線引き

- 判定はページ単位で付ける。`<audio>` は操作部品ではないため。[独自]
- 実測（読み込み後の約 6 秒、再生中・ミュートなし・音量 0 より大きかった長さ）で、見える `controls` が無いまま 3 秒を超えて鳴るもの、自動再生が始まらず測れなかったもの、中を読めなかった iframe は候補（要確認）。[独自]
- 候補が 1 件以上なら要確認、`<audio>` / `<video>` が無ければ対象外、あって候補が無ければ適合。[独自]
- 不適合は付けない。ページの先頭近くに止める・音量を変える手段があるかは実測で確かめていない。[解説書]（手段はメディアのコントロールでなくてよい）
- axe の `no-autoplay-audio` の違反も要確認にとどめる。`controls` 属性しか見ず、ページの別の場所の手段を見ない。[独自]
- `<video>` の自動再生の音も同じ扱い。映像の動きは 2.2.2。[解説書]

## 作るとき

- 音声・動画を自動再生しない。するなら `muted` で始める。
- 自動再生が要るなら、ページの先頭近く（最初の操作部品の前）に止めるボタンか音量の調整を置く。
- 背景の BGM は作らない。作るなら既定で止めておき、利用者が鳴らす。

## 確かめるとき

- **確定**: 無し（不適合も適合の確定も無い）。
- **残る**: 候補があれば、ページの先頭近くに止める・音量を変える手段があるかを目視で確かめる。
- **言い切らない**: `controls` が無いことだけで不適合にしない。候補があるのに適合・対象外にしない。
