# 2.4.4 リンクの目的（文脈における）

- 対象の部品: link
- 要る材料: リンクの名前と、周りのツリー（同じ文・段落・リスト項目・表のセル、直前の見出し）
- 自動チェック: axe の `link-name`（名前の有無だけ）

## 根拠

- [Understanding 2.4.4](https://www.w3.org/WAI/WCAG22/Understanding/link-purpose-in-context.html)（[日本語](https://waic.jp/translations/WCAG22/Understanding/link-purpose-in-context.html)）
  - リンクテキスト単独で分からなくても、「プログラムで判断できる文脈」（同じ文・段落・リスト項目・表のセル、表の見出し、直前の見出し）と合わせて分かればよい。
  - 目的が利用者全般に曖昧なリンク（意図的に行き先を隠すもの）は例外。
  - 行き先の URL が見えることは求めない。
- [G91: リンクの目的を表すテキスト](https://www.w3.org/WAI/WCAG22/Techniques/general/G91)、[H78 / H79 / H80 / H81: 文脈と合わせる](https://www.w3.org/WAI/WCAG22/Techniques/html/H80)、[F63: 文脈が無い](https://www.w3.org/WAI/WCAG22/Techniques/failures/F63)、[F89: 名前の無いリンク](https://www.w3.org/WAI/WCAG22/Techniques/failures/F89)

## 線引き

- リンクの名前だけで、またはリンクの文脈（同じ文・段落・リスト項目・表のセル、直前の見出し）と合わせて、目的が分かれば適合。行き先の URL は見えなくてよい。[解説書]
- ページ上で何かを操作するリンク（「一時停止」「閉じる」「もっと見る」）は、名前がその操作を表していれば目的は分かるので適合。行き先を示していないことを理由に不適合にしない（リンクをボタンの代わりに使う問題は 4.1.2）。[独自]
- 「こちら」「詳しくはこちら」「続きを読む」「more」のように名前だけでは分からないリンクは、同じリスト項目・段落・直前の見出しを確かめる。そこから目的が分かれば適合、分からなければ不適合。周りを確かめる手がかりが無ければ要確認。[解説書]
- 名前が無いリンク（画像だけのリンクで alt が無い）は不適合。[解説書]（F89）
- 同じ名前のリンクが複数あること、名前が長いことだけを理由に不適合にしない。[解説書]（同じ名前で違う行き先は 2.4.4 では文脈で区別できればよい）

## 作るとき

- リンクテキストに行き先の内容を書く（「料金プランを見る」）。「こちら」「詳細」だけにしない。
- 「続きを読む」を並べるカードでは、見出しをリンクにするか、`aria-labelledby` で見出しと「続きを読む」を合わせた名前にする。
- 画像だけのリンクは alt に行き先を書く。
- 同じ名前で違う行き先のリンクが並ぶなら、同じリスト項目や段落に区別できる文脈を置く。

## 確かめるとき

- **確定**: axe の `link-name` の違反（名前が無い）は不適合。
- **残る**: 名前だけで分からないリンクを、文脈と合わせて 1 つずつ見る。
- **言い切らない**: 「こちら」を文脈を見ずに不適合にしない。操作のリンクを「行き先が無い」で不適合にしない。
