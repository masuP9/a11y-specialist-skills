# 2.4.7 Focus Visible

- Scope: whole page (all operable elements)
- Inputs needed: measurement (focus-indicator-check from `@a11y-skills/audit`. Diff of computed styles before and after focus)
- Automated checks: focus-indicator-check

## Rationale

- [Understanding 2.4.7](https://www.w3.org/WAI/WCAG22/Understanding/focus-visible.html) ([Japanese translation](https://waic.jp/translations/WCAG22/Understanding/focus-visible.html))
  - The element focused by keyboard must be shown in a way that makes it identifiable. The browser's default focus ring satisfies this.
  - The form of the indication (outline, background, underline, border) is not asked. How visible it is falls under 2.4.11 to 2.4.13 and 1.4.11.
- [G149: not removing the default focus indicator](https://www.w3.org/WAI/WCAG22/Techniques/general/G149), [C15: changing style on focus](https://www.w3.org/WAI/WCAG22/Techniques/css/C15), [F55: removing focus](https://www.w3.org/WAI/WCAG22/Techniques/failures/F55), [F78: removing the outline](https://www.w3.org/WAI/WCAG22/Techniques/failures/F78)

## Judgment lines

- The verdict is based on measurement that sent focus with Tab. Without measurement, do not judge. [Our interpretation]
- The measurement looks only at changes in the computed styles of outline, box-shadow, background color, border, and text-decoration. Pseudo-elements (`::after`), text color, and changes on the parent element are not visible to it. Even with no change, it cannot be settled that focus is invisible, so **non-conformant is not marked**. If there are elements with no change, mark needs review and list the elements to check visually. [Our interpretation]
- Conformant if there are no elements with no change, the measurement finished to the end, and no elements were skipped. However, add that the size of the color difference was not checked. [Our interpretation]
- Do not mark conformant when the measurement stopped partway, skipped elements (restarted due to a URL change), or there were zero operable elements. [Our interpretation]

## When building

- Do not write `outline: none` / `outline: 0`. If removing it, add an alternative indication (`box-shadow`, background, underline) with `:focus-visible`.
- Show the focus indication around the whole element, or on at least two sides. Do not make it a color change only (1.4.11 needs 3:1).
- Check that the framework's CSS reset does not remove the outline.
- Give custom components (div + tabindex) a `:focus-visible` style too.

## When checking

- **Settled**: none (non-conformant is not marked).
- **Remains**: check visually the elements that showed no change in measurement.
- **Do not assert**: do not mark non-conformant solely because there is no style diff. Do not mark conformant from a measurement that stopped partway.
