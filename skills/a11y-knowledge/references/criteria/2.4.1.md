# 2.4.1 Bypass Blocks

- Scope: blocks of content repeated across related pages
- Inputs needed: full-page tree and DOM, repetition scope, bypass mechanisms and destinations
- Automated checks: axe `bypass` supplies partial evidence; `region` is best practice
- Sources checked: 2026-11-02. WCAG is the 2024-12-12 Recommendation; Understanding / Techniques are living WCAG 2.2 public pages. The following are summaries, not quotations.

## Rationale

### 2.4.1-E01 — Check repeated blocks and available mechanisms

- **Type / source:** [Normative — Bypass Blocks](https://www.w3.org/TR/2024/REC-WCAG22-20241212/#bypass-blocks), [Understanding — Intent / Techniques](https://www.w3.org/WAI/WCAG22/Understanding/bypass-blocks.html#intent).
- **Summary:** Check mechanisms to bypass navigation, headers, advertisements, and similar blocks repeated across related pages. Small repetitions of words, phrases, or individual links are not blocks. User agent and assistive technology mechanisms may be used.
- **Conditions / limits:** Bypassing repetition confined to one page is useful but not required here. Confirmed absence of repeated blocks makes this inapplicable; merely having obtained one page does not.

### 2.4.1-E02 — Landmarks and headings must form a bypassable structure

- **Type / source:** [Technique — ARIA11, Description and Tests](https://www.w3.org/WAI/WCAG22/Techniques/aria/ARIA11#tests), [H69, Description and Tests](https://www.w3.org/WAI/WCAG22/Techniques/html/H69#tests) (Sufficient for grouping repeated material so it can be skipped).
- **Summary:** Check that landmark or heading navigation bypasses repeated blocks. A heading only before a repeated block, or landmarks that do not provide access to the main content, do not establish this.
- **Conditions / limits:** Once effective structure is established, do not require an additional skip link or main landmark. Do not reject reliance on assistive technology merely because a general browser lacks a dedicated shortcut.

### 2.4.1-E03 — Check where skip links take users after activation

- **Type / source:** [Technique — G1, Description and Tests](https://www.w3.org/WAI/WCAG22/Techniques/general/G1#tests) (Sufficient for creating links to skip repeated blocks).
- **Summary:** G1 moves users from the first focusable control to the main content, with subsequent keyboard interaction continuing there. The link may be visible always or only on focus.
- **Conditions / limits:** An href or scrolling alone does not establish success. Do not require `tabindex="-1"` itself; check the actual destination and subsequent interaction. G1 is not the only implementation.

## Judgment lines

- Conform when a mechanism is confirmed to bypass the applicable repeated blocks. Avoid judgments based only on landmark or heading presence. When a heading or similar mechanism provides access to main content, do not return to needs review merely because a skip link is unverified. [Evidence: 2.4.1-E01–E03]
- axe-core 4.14.0 `bypass` checks internal links, headings, main, and similar evidence, with `reviewOnFail: true`. Do not turn missing-evidence incomplete results into confirmed failures, or passes into guarantees of bypassing all repeated blocks. `region` has a best-practice tag, outside audit's default WCAG tags. [Our interpretation: tool mapping. Implementation checked: `node_modules/axe-core/axe.js`, `packages/a11y-audit/src/constants.ts`]

## Judgment examples

- **Conformant:** A main-content heading follows repeated navigation and heading navigation reaches that content. Do not flag merely because main or a skip link is absent. [Evidence: 2.4.1-E02]
- **Non-conformant:** Repeated navigation must be traversed sequentially every time, and no bypass through headings, landmarks, links, collapsing, or other mechanisms is available. [Evidence: 2.4.1-E01–E03]
- **Inapplicable:** There are no blocks repeated across pages, only a shared individual link. [Evidence: 2.4.1-E01]
- **Needs review:** Headings exist only before the repeated block, and alternative bypass mechanisms are unverified. Inspect destination structure and interaction. [Our interpretation: inspection policy. Evidence: 2.4.1-E02–E03]

## When building

- Use header / nav / main and a heading at the start of main content to provide a structure that allows users to bypass repetition and reach needed content. [Evidence: 2.4.1-E02]
- If adding a skip link, make it the first available control, visible on focus, and allow interaction to continue from main content after activation. [Evidence: 2.4.1-E03]

## When checking

- **Settled:** Results of checking repetition against available mechanisms, placement, and behavior. [2.4.1-E01–E03]
- **Remains:** Uncollected pages and iframes, the destination and next Tab after link activation, behavior not established by structure alone.
- **Do not assert:** A 2.4.1 failure solely from missing main/skip links or a `region` violation. [Evidence: 2.4.1-E01–E03. Tool classification is author policy]
