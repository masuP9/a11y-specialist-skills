# 2.4.1 Bypass Blocks

- Scope: whole page
- Inputs needed: accessibility tree of the whole page (document order of landmarks and headings; the snapshot from `page-snapshot`)
- Automated checks: axe `bypass`, `region`

## Rationale

- [Understanding 2.4.1](https://www.w3.org/WAI/WCAG22/Understanding/bypass-blocks.html) ([Japanese translation](https://waic.jp/translations/WCAG22/Understanding/bypass-blocks.html))
  - There must be a means to skip blocks repeated across multiple pages (header, navigation) and get to the main content. One means is enough.
  - Examples of means: a skip link, headings (heading navigation in assistive technology), landmarks (ARIA11). Any one technique satisfies it.
  - If there are no repeated blocks, not applicable.
- [G1: skip link](https://www.w3.org/WAI/WCAG22/Techniques/general/G1), [H69: separating with headings](https://www.w3.org/WAI/WCAG22/Techniques/html/H69), [ARIA11: landmarks](https://www.w3.org/WAI/WCAG22/Techniques/aria/ARIA11)

## Judgment lines

- If repeated blocks such as the header or navigation are banner / navigation landmarks, or there is a heading near the beginning of the main content, conformant. It is enough that the repeated blocks can be skipped, so neither main nor a skip link is required. [Understanding] (one technique is enough)
- Do not mark needs review because a skip link could not be confirmed. [Understanding]
- If there are neither landmarks nor headings, needs review (look at the whole page to see whether there really are repeated blocks). [Our interpretation]

## When building

- Wrap the header in `<header>` (banner), navigation in `<nav>`, and the main content in `<main>`. This alone satisfies 2.4.1.
- Put an h1 at the beginning of the main content.
- If adding a skip link ("Skip to content"), make it the first focusable element on the page and visible on focus. `tabindex="-1"` on the `href="#main"` target is not required, but some implementations add it for Safari's behavior.

## When checking

- **Settled**: none. axe `bypass` reports a violation only when there is no means at all.
- **Remains**: check, in the snapshot's document order, whether the repeated blocks can be skipped by landmarks or headings.
- **Do not assert**: do not mark the absence of a skip link non-conformant. Do not mark the absence of main non-conformant.
