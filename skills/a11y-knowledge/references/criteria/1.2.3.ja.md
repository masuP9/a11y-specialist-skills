# 1.2.3 音声解説又はメディアに対する代替（収録済み）

- 対象: 同期したメディアに含まれる収録済み映像
- 要る材料: 映像と主音声、音声解説又はテキストの代替、操作による分岐・結果、代替への到達手段
- 自動チェック: track・リンクの検出は候補。内容と再生・操作を照合して判定する
- 原文確認日: 2026-11-02。WCAGは2024-12-12勧告、Understanding / Techniquesは随時更新の公開ページ。以下は引用ではなく要約。

## 根拠

### 1.2.3-E01 — レベルAの二つの達成経路と対象を確認する

- **種別・出典:** [規範 — Audio Description or Media Alternative (Prerecorded)](https://www.w3.org/TR/2024/REC-WCAG22-20241212/#audio-description-or-media-alternative-prerecorded)、[Understanding — Intent](https://www.w3.org/WAI/WCAG22/Understanding/audio-description-or-media-alternative-prerecorded.html#intent)。
- **要約:** 音声解説又は時間依存メディアの代替のどちらかを確認する。テキストの代替であり、その旨が明示されたメディアは例外。
- **適用条件・限界:** 同等なテキストで本基準を満たしても、AAの1.2.5の達成が自動的に決まるわけではない。映像のみは1.2.1と分ける。本文の要約や関連資料があるだけで例外にしない。

### 1.2.3-E02 — 代替テキストには映像・音声・操作の結果を含める

- **種別・出典:** [Technique — G69「Description / Tests」](https://www.w3.org/WAI/WCAG22/Techniques/general/G69#description)、[G58「Description / Tests」](https://www.w3.org/WAI/WCAG22/Techniques/general/G58#description)（併用してSufficient）。
- **要約:** 完成版の音声と視覚情報を順序どおりに伝え、時間依存の操作があれば同じ選択・結果を得る手段も用意する。G58では対応する代替へのリンクと戻る手段を確かめる。
- **適用条件・限界:** 会話だけの文字起こしは、映像だけの情報が欠ければ不十分。制作台本も完成版と照合する。G58の隣接リンクを唯一の方法にせず、対応する代替を利用できるか確認する。

### 1.2.3-E03 — 主音声の充足と音声解説の経路を確認する

- **種別・出典:** [Understanding — Intentの注記](https://www.w3.org/WAI/WCAG22/Understanding/audio-description-or-media-alternative-prerecorded.html#intent)、[Technique — G78「Description / Tests」](https://www.w3.org/WAI/WCAG22/Techniques/general/G78#description)（Sufficient）。
- **要約:** 重要な視覚情報が主音声ですべて伝わるなら追加の音声解説は不要。必要な解説は選択式又は既定の音声に含められる。
- **適用条件・限界:** 音声があることだけで十分としない。「こちら」のような指示、無言の実演、画面内文字を映像と照合する。通常の音声解説と拡張音声解説の境界は[1.2.5-E04と線引き](./1.2.5.ja.md)に従う。話者1人で重要な時間依存の視覚情報がない場合の静的な代替は[1.2.5-E03](./1.2.5.ja.md)のG203の条件を使う（1.2.3にもSufficient）。

## 線引き

- 音声解説又は映像・音声・操作を同等に伝えるテキストの経路が成立すれば適合。一方の欠落だけでFailにしない。どちらも不足すると確認できれば不適合。[根拠: 1.2.3-E01–E03]
- 主音声ですべての重要な視覚情報が伝わるものは、追加トラックなしで適合とする。単に発話が途切れない動画と取り違えない。[根拠: 1.2.3-E03]
- 元のテキストを超える情報を加えず、テキストの代替と明示されたメディアは例外として指摘しない。後から置いた会話だけの書き起こしをこの例外にしない。[根拠: 1.2.3-E01]
- `descriptions` のtrack、音声解説版へのリンク、`aria-describedby` は提供方法の手がかり。存在だけで適合にせず、対象との対応・内容・利用可能性を確認する。track方式の限界は[1.2.5-E05](./1.2.5.ja.md)を参照。[根拠: 1.2.3-E02–E03。確認手順は独自]

## 判断例

- **適合:** 動画の会話・効果音・画面の操作・表示結果を順序どおりに説明したテキストが利用できる。1.2.5は別途評価する。[根拠: 1.2.3-E01–E02]
- **適合:** 実演動画で、すべての重要な動作と結果を主音声でも説明している。追加の音声解説トラックを要求しない。[根拠: 1.2.3-E03]
- **例外で指摘しない:** 説明文の代替と明示された動画が、その情報だけを提示している。[根拠: 1.2.3-E01]
- **不適合:** 無言の実演が重要な研修動画に会話だけの文字起こししかなく、音声解説もない。[根拠: 1.2.3-E01–E03]
- **不適合:** 動画内の分岐で購入・選択できるが、テキストの代替には同じ結果を得る手段がなく、音声解説の経路も成立しない。[根拠: 1.2.3-E02]
- **要確認:** 音声解説版へのリンクはあるが再生できない。対応版の取得・解説内容と利用可能性を確認する。[独自: 検査例。根拠: 1.2.3-E03]

## 作るとき

- 対象レベルに合わせて達成経路を選ぶ。Aのテキスト経路では会話以外の情報と操作も含め、AAの音声経路は[1.2.5](./1.2.5.ja.md)と合わせて設計する。[根拠: 1.2.3-E01–E03]
- 代替を完成版に同期し、どのメディアの代替か分かるようにして到達手段を提供する。[根拠: 1.2.3-E02]

## 確かめるとき

- **確定:** 選んだ経路の内容・順序・操作・利用可能性と例外を照合した結果。[根拠: 1.2.3-E01–E03]
- **残る:** 視覚だけの情報、会話以外の音、分岐・操作、再生できない別版。
- **言い切らない:** 字幕・文字起こし・trackがあるだけで適合にしない。欠落する情報・操作と再生時刻を記録する。Aの適合をAA全体へ広げない。[根拠: 1.2.3-E01–E03。証跡形式は独自]
