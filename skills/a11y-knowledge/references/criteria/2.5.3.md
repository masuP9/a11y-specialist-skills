# 2.5.3 Label in Name

- Scope: Controls with visible labels containing text or images of text
- Materials: Screen in the same state, individual labels, computed names, and name/description references
- Automated check: axe `label-content-name-mismatch`. Check detection scope and string-comparison limits
- Sources checked: 2026-11-02. WCAG: Recommendation of 2024-12-12; Understanding / Techniques: living published pages. The following are summaries, not quotations.

## Evidence

### 2.5.3-E01 — Do not universally require exact or prefix matches

- **Type / source:** [Normative — Label in Name](https://www.w3.org/TR/2024/REC-WCAG22-20241212/#label-in-name), [Technique — G208 “Description / Tests”](https://www.w3.org/WAI/WCAG22/Techniques/general/G208#description) (Sufficient).
- **Summary:** Check that the name contains the visible label string. Additional context is allowed. Placing the visible label at the start is a best practice, not a requirement.
- **Conditions / limits:** Images of text are included. Having all words is insufficient if reordering or interspersing words breaks the label's intact string.

### 2.5.3-E02 — Separate individual labels from descriptions

- **Type / source:** [Technique — G211 “Description / Examples / Tests”](https://www.w3.org/WAI/WCAG22/Techniques/general/G211#description) (Sufficient), [Understanding — Identifying label text / Accessible Name and Description Computation specification](https://www.w3.org/WAI/WCAG22/Understanding/label-in-name.html#identifying-label-text-for-components).
- **Summary:** Usually compare the individual nearby label; do not require every heading, group label, and instruction in the name. An intervening short hint alone does not exclude a label.
- **Conditions / limits:** Do not fail capitalization/punctuation differences alone. Parenthetical information may be treated as a description, but important requirements/format information must remain programmatically available elsewhere. A placeholder is a candidate when no other nearby label exists. This does not change the author policy failing placeholder-only labeling under [3.3.2](./3.3.2.md).

### 2.5.3-E03 — Distinguish linguistic text from symbols

- **Type / source:** [Understanding — Text labels “express something in human language”](https://www.w3.org/WAI/WCAG22/Understanding/label-in-name.html#text-labels-express-something-in-human-language).
- **Summary:** Do not mechanically match symbolic characters such as “B” for bold or “>” used as an arrow. Formula labels are different: preserve the formula in the name.
- **Conditions / limits:** Icon-only controls without visible text labels are outside this criterion. Assess names and alternatives under other criteria.

### 2.5.3-E04 — Check missing, overridden, and interrupted names

- **Type / source:** [Failure — F96 “Examples / Tests”](https://www.w3.org/WAI/WCAG22/Techniques/failures/F96#examples), [Failure — F111 “Description / Tests”](https://www.w3.org/WAI/WCAG22/Techniques/failures/F111#description).
- **Summary:** Check visible text labels with no accessible name, names overridden by different strings, and label strings interrupted by hidden text.
- **Conditions / limits:** Compare the actual name rather than failing the presence of `aria-label`. Text announced only as a description does not repair a missing part of the name.

## Judgment lines

- Pass when the label, interpreted using E02–E03, appears intact and in order in the name. Neither a non-prefix match nor additional context alone is Fail. [Evidence: 2.5.3-E01–E03]
- Fail confirmed missing, replaced, or interrupted names on controls with visible text labels. Reproducing a failed voice command is not a prerequisite. [Evidence: 2.5.3-E04]
- Separate name availability under [4.1.2](./4.1.2.md) and visible-label descriptiveness under [2.4.6](./2.4.6.md). Matching “Search” labels/names does not resolve descriptiveness if the actual function is deletion. [Our interpretation: cross-criterion example. Evidence: 2.5.3-E01, 2.4.6-E03]

## Judgment examples

- **Pass:** Visible “検索” with name “サイト内を検索”. The string is included even though it is not a prefix. [Evidence: 2.5.3-E01]
- **Pass:** Visible “First Name:” with name “first name”. Do not flag capitalization and punctuation differences alone. [Evidence: 2.5.3-E02]
- **Pass:** “Date (YYYY-MM-DD)” has name “Date”, with the format associated as a description. [Evidence: 2.5.3-E02]
- **Out of scope:** A symbolic “B” bold icon named “Bold”. Do not require adding the symbolic B to the name. [Evidence: 2.5.3-E03]
- **Fail:** Visible “Download specification” becomes “Download gizmo specification” through intervening hidden text. Containing every label word is insufficient. [Evidence: 2.5.3-E04]
- **Needs review:** Only an image button's alt is available; its image text is unverified. Compare the actual image and computed name. [Our interpretation: inspection example. Evidence: 2.5.3-E01]

## When building

- Use the individual visible label in the name without overriding or interrupting it with explanations. Usually put it first. Preserve associations for information moved into descriptions. [Evidence: 2.5.3-E01–E02, E04]

## When checking

- **Implementation checked:** axe-core 4.14.0 rule definition, matches/evaluate, `runAxeAudit`, and `DEFAULT_AXE_TAGS`. This rule is not experimental and is selected by default WCAG tags. A runtime check produced violations for a mismatching button and passes for a matching one.
- **Detection scope:** Widget roles permitting names from content, with an ARIA-derived name and visible internal text. It does not cover ordinary text inputs with adjacent labels or recognition of text in images. Switches and similar controls may produce incomplete on mismatches requiring value/label distinction.
- **Confirmed:** Compare violations against label scope, symbols, supplemental information, and computed names before confirming Fail. Specify missing information for incomplete. Check visible labels when other name rules find missing names too. [Evidence: 2.5.3-E01–E04]
- **Do not overclaim:** Passes/zero candidates do not establish whole-SC Pass. Images of text, external labels, changed states, and name/description distinctions remain.
