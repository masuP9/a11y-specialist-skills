# 2.5.5 Target Size (Enhanced) (AAA)

- Components in scope: button, link (links in running text are an exception)
- Inputs needed: measurement (target-size-check from `@a11y-skills/audit`)
- Automated checks: target-size-check

Because it is AAA, it is not asked by default. Check it only in projects with a policy of making targets 44px or larger. The AA criterion 2.5.8 is a separate file ([2.5.8](./2.5.8.md)).

## Rationale

- [Understanding 2.5.5](https://www.w3.org/WAI/WCAG22/Understanding/target-size-enhanced.html) ([Japanese translation](https://waic.jp/translations/WCAG22/Understanding/target-size-enhanced.html))
  - 44 × 44 CSS px or more. Exceptions: another target with the same function, links in running text, the user agent's default presentation, a particular presentation is essential.
  - Unlike 2.5.8 (24px, with a spacing exception), there is no spacing exception.

## Judgment lines

- The judgment rule is the same as 2.5.8, with a threshold of 44px and no spacing exception. [Understanding]
- Because it is AAA, do not count non-conformance in the "number of problems". When pointing it out, state clearly that it is AAA. [Our interpretation]

## When building

- Make buttons and icons 44 × 44px or more (the width of a finger on mobile).
- When you want it to look small, keep the pressable area (padding) at 44px even if the appearance is small.

## When checking

- **Settled**: the 44px verdict of target-size-check.
- **Remains**: whether it falls under the running-text exception.
- **Do not assert**: do not mix it into the AA verdict.
