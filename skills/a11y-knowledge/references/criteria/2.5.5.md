# 2.5.5 Target Size (Enhanced) (AAA)

- Scope: pointer input targets (buttons, links, etc.)
- Inputs needed: target-size-check measurements, actual activation areas, and exception checks
- Automated checks: target-size-check

Not assessed in the default AA evaluation. Check when the project includes AAA or a 44px policy. [Our interpretation: evaluation scope]

- Sources checked: 2026-11-01. WCAG refers to the 2024-12-12 Recommendation; Understanding / Techniques are the continuously updated WCAG 2.2 published pages. The following are summaries, not quotations.

## Evidence

### 2.5.5-E01 — Equivalent targets must be on the same page and at least 44px

- **Type / source:** [Normative — WCAG 2.2 “Target Size (Enhanced)”](https://www.w3.org/TR/2024/REC-WCAG22-20241212/#target-size-enhanced), [Understanding — “Intent”](https://www.w3.org/WAI/WCAG22/Understanding/target-size-enhanced.html#intent).
- **Summary:** For a small target with an equivalent link or control, check that the equivalent is on the same page and at least 44×44 CSS px. Also check exceptions for UA-determined sizing unmodified by the author and particular presentations essential to the information conveyed.
- **Conditions / limits:** Merely having a link with the same function is insufficient. Do not use 2.5.8's spacing exception.

### 2.5.5-E02 — Do not copy the inline exception from 2.5.8

- **Type / source:** [Normative — WCAG 2.2 “Target Size (Enhanced)”](https://www.w3.org/TR/2024/REC-WCAG22-20241212/#target-size-enhanced), [Understanding — “Intent”, Inline targets](https://www.w3.org/WAI/WCAG22/Understanding/target-size-enhanced.html#intent).
- **Summary:** The exception concerns targets within a sentence or block of text. A target comprising a whole sentence outside a block of text remains subject to the size requirement.
- **Conditions / limits:** CSS display:inline alone does not establish the exception. Do not directly import 2.5.8's condition about constraints from non-target text line height. C44's Tests also use that wording; prioritize the normative wording for this criterion's exception decisions.

### 2.5.5-E03 — Measure the pointer activation area rather than visual size

- **Type / source:** [Normative — WCAG 2.2 “target”](https://www.w3.org/TR/2024/REC-WCAG22-20241212/#dfn-targets), [Technique — C44 “Examples” / “Tests”](https://www.w3.org/WAI/WCAG22/Techniques/css/C44#tests) (Sufficient).
- **Summary:** A small icon can meet the size requirement when its activation area is at least 44×44 CSS px. C44 applies minimum dimensions and padding to the link itself.
- **Conditions / limits:** Do not include noninteractive outer whitespace. CSS declarations or rectangle measurements alone do not prove the actual activation area for covered portions or unusual shapes.

## Judgment boundaries

- Do not confirm failure from a measurement below 44px alone. Check equivalent, inline, UA, and essential exceptions and the actual activation area. [Evidence: 2.5.5-E01–E03]
- Exclude it from default AA issue counts; label improvement suggestions as AAA. When AAA is in scope, report failures within that scope. [Our interpretation: evaluation scope and reporting policy]
- Tool exception candidates require review. Shadow DOM, iframes, and elements with script-only interactions can escape detection. Do not declare undetected targets conformant. [Our interpretation: tool mapping. Implementation: [runTargetSizeCheck.ts](../../../../packages/a11y-audit/src/playwright/runTargetSizeCheck.ts)]

## Judgment examples

- Apply the inline exception to links in prose and footnote links or help icons within or at the end of a sentence; do not require enlarging them to 44px. A help icon in a standalone toolbar is not this example. [Evidence: 2.5.5-E02]
- When another button on the same page performs the same action and is at least 44×44 CSS px, apply the equivalent-target exception to the smaller target. Also apply the UA exception to native controls whose UA-determined size is unmodified; do not return an established exception to review for small size alone. [Evidence: 2.5.5-E01]

## When building

- Give buttons and icons actual activation areas of at least 44×44 CSS px. Use padding on the interactive element to retain a smaller visual appearance. [Evidence: 2.5.5-E03]

## When checking

- **Established:** Results of checking measured dimensions, actual activation areas, and exceptions. [2.5.5-E01–E03]
- **Remaining:** Dimensions of same-page equivalent targets, sentence/block-of-text context, author modifications to UA sizing, and essential presentation.
- **Do not conclude:** Meeting 2.5.8 through spacing does not establish 2.5.5 conformance. Do not mix it into AA issue counts. [2.5.5-E01]
