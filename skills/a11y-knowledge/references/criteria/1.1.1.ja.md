# 1.1.1 非テキストコンテンツ

- 対象の部品: image（img、figure）、画像だけの button / link
- 要る材料: アクセシビリティツリー（名前・alt 属性・親の名前）、画像の中身（スクリーンショット）
- 自動チェック: axe の `image-alt` / `input-image-alt` / `role-img-alt`

## 根拠

- [Understanding 1.1.1](https://www.w3.org/WAI/WCAG22/Understanding/non-text-content.html)（[日本語](https://waic.jp/translations/WCAG22/Understanding/non-text-content.html)）
  - 代替テキストは「同じ目的を果たす」もの。画像の見た目の説明ではなく、その画像がその場で果たしている役割（リンクなら行き先、ボタンなら操作）を表せばよい。
  - 純粋な装飾・見た目の整形だけ・利用者に見えないものは、支援技術が無視できるように実装すればよい（`alt=""`）。
  - テキストの代替が「十分か」は文脈で決まる。短い名前で足りる画像もあれば、グラフのように長い説明が要る画像もある。
- [H37: img 要素の alt 属性](https://www.w3.org/WAI/WCAG22/Techniques/html/H37)、[H67: 装飾画像の alt を空にする](https://www.w3.org/WAI/WCAG22/Techniques/html/H67)、[ARIA6: aria-label](https://www.w3.org/WAI/WCAG22/Techniques/aria/ARIA6)

## 線引き

- 中身がその画像だけのボタンやリンクは、ボタンやリンク自体に名前（aria-label、title、見えない文字など）があれば、中の画像に alt が無くても適合。親の名前が代替テキストの役を果たす。[解説書]（同じ目的を果たすテキストがあればよい）
- 画像だけのボタンで、名前が無い、または名前が「button」「画像」「icon」「ファイル名」のように操作を表していなければ不適合。[解説書]
- alt 属性そのものが無い画像は、必ず不適合とは限らないが、適合にはしない。情報を持つと読める画像（リンクやボタンの中、見出しの中のロゴ、幅の大きいメイン画像、周りに同じ内容の文字が無い画像）なら不適合。装飾とも読めるなら要確認（画像を見て決める）。[独自]
- `alt=""` は装飾の宣言。装飾なら適合。情報を持つと読める画像（画像の中に文字がある、ロゴ、文字入りバナー）なら不適合。[解説書]
- 画像の中に文字があれば装飾とは判断しない。[独自]（ロゴを画像を見て装飾と判断し、適合にした誤りから）
- 幅の大きいメインの画像やカルーセルのスライドは、文字が無くても装飾とは判断しない（alt 属性が無ければ不適合）。[独自]（文字の無いメイン画像を、画像を見て飾りと見なした誤りから）
- 文字の無い写真やイラストが、すぐ横の文字と同じことを表すだけなら、中身が見えても情報を持つ画像とは判断しない（`alt=""` なら適合）。[独自]（カードの見出しの横の写真を「情報を持つのに alt が空」と不適合にした誤りから）
- `aria-hidden="true"` の画像は原則として対象外（読み上げで無視される）。ただし、あとで表示されて読み上げの対象になると強く推測できるもの（カルーセルのスライド: 同じ大きさの画像が横に並び、画面の外にあり、「次のスライド」のような切り替えボタンがある）は、隠れていない状態で判断する。[独自]
- 名前が画像の中身を表していない（「画像」「写真」「image」「photo」、ファイル名、「spacer」）なら不適合。[解説書]
- 名前が中身を表す語（キャラクター名・人名・商品名）なら、「説明が足りないかもしれない」という推測で不適合にしない。周りの情報から足りないことがはっきり分かる場合（グラフや文字の多いお知らせ画像なのに短い名前だけ）だけ不適合、疑わしいだけなら要確認。[独自]
- リンクの 1.1.1 はリンク自体には問わず、中の画像の側で見る（部品の索引で link に 1.1.1 が無いのはそのため）。[独自]

## 作るとき

- 画像だけのボタン・リンクは、`aria-label` か見えないテキストで、画像ではなく操作・行き先の名前を付ける。中の `<img>` は `alt=""` にする。
- 情報を持つ画像の alt は、その場で果たしている役割を書く。ロゴなら組織名、グラフなら要点（長ければ本文かキャプションに書き、alt はそれを指す）。
- 装飾の画像は `alt=""`（または CSS 背景）。`alt` を省略しない。省略は「忘れた」と区別できない。
- カルーセルのように後で表示される画像にも alt を付ける。`aria-hidden` で隠している間も alt は要る。
- 画像の中の文字は alt に入れる（文字画像の是非は 1.4.5）。

## 確かめるとき

- **確定**: axe の `image-alt` / `input-image-alt` / `role-img-alt` の違反（alt 属性が無い `<img>` など）は不適合。これらの pass は適合に数えてよい（名前があること）。
- **残る**: 名前が中身を表しているか、`alt=""` の画像が本当に装飾か。画像の中身を見ないと決められない。
- **言い切らない**: alt 属性が無い画像を、画像を見ずに不適合にも適合にもしない（上の線引きのとおり要確認）。名前がある画像を「説明が足りないかも」で不適合にしない。
