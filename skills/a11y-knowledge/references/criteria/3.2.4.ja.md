# 3.2.4 一貫した識別性

- 対象: 複数ページ（link、button、入力欄などの部品）
- 要る材料: 各ページの aria snapshot（`page-snapshot`）。部品の名前・役割・置かれたランドマーク・リンク先。先に [cross-page](../cross-page.ja.md) を読む
- 自動チェック: 無し

## 根拠

- [Understanding 3.2.4](https://www.w3.org/WAI/WCAG22/Understanding/consistent-identification.html)（[日本語](https://waic.jp/translations/WCAG22/Understanding/consistent-identification.html)）
  - 複数のページで「同じ機能」を持つ部品は、一貫して識別される（同じ名前・代替テキスト）こと。
  - 「一貫」は「全く同じ」ではない。利用者が同じ機能だと分かればよい（「検索」と虫眼鏡のアイコン「検索」）。
  - 同じ名前でも機能が違えば、名前を変えるべき。
- [G197: 同じ機能には同じラベル](https://www.w3.org/WAI/WCAG22/Techniques/general/G197)、[F31: 同じ機能に違う名前](https://www.w3.org/WAI/WCAG22/Techniques/failures/F31)

## 線引き

- 対象は、同じ部品が繰り返し出てくるもの（グローバルナビ・検索・アカウント操作・フッターのリンクのように、複数のページで同じ役目で出てくる部品）。働きやリンク先が同じでも、同じ部品の繰り返しでなければ同じ識別は求めない。フッターの「お問い合わせ」と本文の「サポートチームへのお問い合わせ」、トップのカードと一覧ページの項目は、それぞれ別の部品。[解説書]
- 「一貫している」は「全く同じ」ではない。判断の軸は、片方を覚えた利用者が、もう片方を同じ働きだと気づけるか。「4 ページへ」と「5 ページへ」のような番号だけが違うもの、文字の「検索」と名前が「検索」の虫眼鏡のアイコンは一貫している。[解説書]
- リンク先が違っても同じ働き（言語の切り替え）のことがある。同じアイコンでも働きが違えば名前は変えるべき。[解説書]
- 段 1（同じ部品か）: 置かれた場所（ランドマーク）と役目で決める。banner / navigation / contentinfo / search の部品どうしは、同じ働きなら同じ部品として比べる。本文（main）の部品は、どのページでも同じ役目で出てくるもの（各ページの「保存」ボタン、ページ送り）だけを同じ部品にする。1 ページだけ名前が違っても、ほかのページの同じ役目の部品に当たるなら同じ部品に入れる。置かれた場所や役目の違うもの（本文の部品とフッターの部品、トップのカードと一覧ページの項目）は、リンク先が同じでも同じ部品にしない。[独自]（誤判定の型から）
- 段 2（同じ呼び方か）: 同じ働きで呼び方が違うもの（「お問い合わせ」と「Contact」）は別。番号だけが違う、現在のページだけ表記が変わる、片方の名前がもう片方の主な語をそのまま含み説明や飾り（絵文字）が足されているだけ、のものは同じ。略語と正式名のように判断が分かれるものは要確認。[独自]
- 候補の絞り方: 文中のリンク（親の直下に文字がある）は候補から外す。ただし navigation / banner / contentinfo / search の中のものは外さない。checkbox は外す（名前が無いものは見た目でしか同じ部品か分からない）。ボタンは残すが、名前だけでは働きが分からないものは要確認。[独自]
- ページ内へのリンク（`#` で始まる href）は、各ページの自分自身への URL になるので、リンク先で同一視しない。[独自]
- 多数派・同数・ビューポートの扱いは [cross-page](../cross-page.ja.md)。

## 作るとき

- 同じ機能の部品は共通の部品にし、名前を 1 か所で決める（「検索」「お問い合わせ」「ログイン」）。
- アイコンだけのボタンの名前（aria-label）も、ページをまたいで同じにする。
- 「お問い合わせ」と「Contact」のように、ページによって言語や言い回しを変えない。
- 同じアイコンを違う機能に使わない。

## 確かめるとき

- **確定**: 無し。
- **残る**: 各ページの snapshot から部品を拾い、段 1 で同じ部品の組にし、段 2 で呼び方の組に分け、食い違いを多数派で判定する。
- **言い切らない**: 別の部品（場所や役目が違う）を同じ識別が無いとして不適合にしない。飾りが足されただけの違いを不適合にしない。
