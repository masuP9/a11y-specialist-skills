# 2.3.1 3回の閃光、又は閾値以下

- 対象: ページ上のすべての内容。適合に使わない内容（広告、埋め込み、適合の対象外としている部分）も含む
- 要る材料: 点滅する箇所、1秒間の明暗の切り替わりの回数、同時に点滅する面積、明るい状態と暗い状態の色（相対輝度・赤の度合い）、最も大きく表示したときの大きさ、ループの有無
- 自動チェック: なし。axe-core 4.14.0に点滅を測るルールはない（`blink` / `marquee` は `wcag222` で2.2.2用）。`@a11y-skills/audit` にもない。`auto-play-detection` は動くものの候補を出すが、閃光の回数・面積・明暗は測らない
- 原文確認日: 2026-11-10。WCAGは2024-12-12勧告。Understandingは2025-09-17更新、G19・G176・G15は2025-07-15更新の公開ページ（随時更新）。以下は引用ではなく要約。

## 根拠

### 2.3.1-E01 — どの内容にも適用する

- **種別・出典:** [規範 — Three Flashes or Below Threshold](https://www.w3.org/TR/2024/REC-WCAG22-20241212/#three-flashes-or-below-threshold)、[適合要件5 — Non-Interference](https://www.w3.org/TR/2024/REC-WCAG22-20241212/#cc5)、[Understanding — Intent](https://www.w3.org/WAI/WCAG22/Understanding/three-flashes-or-below-threshold.html#intent)。
- **要約:** 1秒間に3回を超えて閃光するものがなく、又は閃光が一般閃光と赤色閃光の閾値以下であること。この基準を満たさない内容はページ全体の利用を妨げ得るので、適合に使わない内容も含めてページのすべての内容に適用する。閃光は1秒でも許されず、止める手段を付けることも解決にならない（止める前に発作が起き得る）。
- **適用条件・限界:** 表示装置やコンピューターが起こすちらつきは対象外で、内容そのものが起こす閃光を対象にする。気を散らす問題である点滅（blinking）は[2.2.2](./2.2.2.ja.md)で扱い、1秒に3回以上なら閃光にも当たる。

### 2.3.1-E02 — 回数で決める

- **種別・出典:** [用語 — general flash and red flash thresholds](https://www.w3.org/TR/2024/REC-WCAG22-20241212/#dfn-general-flash-and-red-flash-thresholds)、[用語 — flash](https://www.w3.org/TR/2024/REC-WCAG22-20241212/#dfn-flashes)、[Technique — G19「Description」](https://www.w3.org/WAI/WCAG22/Techniques/general/G19#description)（Sufficient）。
- **要約:** どの1秒間でも一般閃光と赤色閃光がそれぞれ3回以下なら閾値以下。閃光は相対輝度の反対向きの変化の組（明→暗、又は暗→明の2回の切り替わり）。3回は6回の切り替わりで、7回の切り替わり（3.5回）から超える。用語の注記4は、1秒に3回以下なら解析ツールなしで合格すると書く。
- **適用条件・限界:** G19は面積に関係なく3回以下にする方法で、基準より厳しいが確かめやすい。注記は5.1節により参考情報だが、回数の条件そのものは定義の本文にある。

### 2.3.1-E03 — 面積で決める

- **種別・出典:** [用語 — general flash and red flash thresholds](https://www.w3.org/TR/2024/REC-WCAG22-20241212/#dfn-general-flash-and-red-flash-thresholds)、[Understanding — Intent](https://www.w3.org/WAI/WCAG22/Understanding/three-flashes-or-below-threshold.html#intent)、[Technique — G176「Description」](https://www.w3.org/WAI/WCAG22/Techniques/general/G176#description)（Sufficient）。
- **要約:** 同時に点滅する面積の合計が、どの10度の視野でも25%以下なら閾値以下。Understandingは10度の視野を341×256 CSS px（87,296 CSS px）で表し、その25%は21,824 CSS px。G176は、ほかに点滅がない1か所の点滅で、隣り合う面積が21,824画素より小さければ形によらず合格とする。内容は利用者が見る最も大きな倍率で、UAの標準の拡大率で評価する。全画面でも再生できる動画は全画面で評価する。ループする短い動画（GIFなど）はループさせて評価する。
- **適用条件・限界:** 面積は同時に、かつ隣り合って点滅する部分の合計。画面に近づいて見る人や拡大して見る人には、基準上は合格する面積でも影響があることを注記が認めている。

### 2.3.1-E04 — 明暗と赤の条件

- **種別・出典:** [用語 — general flash and red flash thresholds](https://www.w3.org/TR/2024/REC-WCAG22-20241212/#dfn-general-flash-and-red-flash-thresholds)、[用語 — relative luminance](https://www.w3.org/TR/2024/REC-WCAG22-20241212/#dfn-relative-luminance)、[Understanding — Intent](https://www.w3.org/WAI/WCAG22/Understanding/three-flashes-or-below-threshold.html#intent)。
- **要約:** 一般閃光は、相対輝度が最大（1.0）の10%以上変わる反対向きの変化の組で、暗い側の相対輝度が0.80未満のもの。赤色閃光は、飽和した赤を含む反対向きの変化の組。WCAG 2.2の注記は、一方の状態の R/(R+G+B) が0.8以上で、CIE 1976 UCS色度図での差が0.2を超えるものを、現場での新しい作業上の定義として示す。細かく均一な模様（1辺が視野0.1度未満の市松模様、ホワイトノイズなど）の点滅は閾値を超えない。sRGB以外の色空間の動画は、最も広いダイナミックレンジの版で評価する。
- **適用条件・限界:** 赤色閃光の作業上の定義は注記で、参考情報。

### 2.3.1-E05 — ツールでの確認と警告

- **種別・出典:** [Technique — G15「Description」](https://www.w3.org/WAI/WCAG22/Techniques/general/G15#description)（Sufficient）、[Understanding — Examples](https://www.w3.org/WAI/WCAG22/Understanding/three-flashes-or-below-threshold.html#examples)。
- **要約:** 1秒に3回以下ならG19、小さな1か所の点滅ならG176の簡単な確かめ方が使える。それ以外は、すべての要素を時間に沿って追う解析ツールが要る。警告を出すこともできるが、見落とされたり、子どもが読めなかったりする。例として、閃光する面積を閾値より小さくした銃口の閃光の動画と、稲妻の閃光を1秒に3回までに編集した映画がある。
- **適用条件・限界:** 特定のツールの結果を唯一の判定方法にしない。

## 線引き

- どの1秒間でも閃光が3回以下（明暗の切り替わりが6回以下）ならPass。面積や明暗を測らない。[根拠: 2.3.1-E02]
- 3回を超えても、同時に点滅する面積の合計が、341×256 CSS pxのどの範囲でも21,824 CSS px（25%）以下ならPass。全画面で再生できる動画は全画面の大きさで、ループする動画はループさせて確かめる。[根拠: 2.3.1-E03]
- 3回を超え、面積も閾値を超えるなら、明るい状態と暗い状態の色で一般閃光と赤色閃光の条件を確かめる。CSS・JSのアニメーションやGIFは指定の色や各コマの色から計算する。動画は最も明るいコマと最も暗いコマの2つを測る。どちらかの条件を満たせばFail、どちらも満たさなければPass。測れなければ要確認とし、解析ツール（PEAT等）で確かめる。[独自: ツールがないときに2コマで測る手順。根拠: 2.3.1-E04, E05]
- 細かく均一な模様（1辺が視野0.1度未満）の点滅は、閾値を超えないものとして扱う。[根拠: 2.3.1-E04]
- 押すまで再生されない動画、再生前の警告、`prefers-reduced-motion` を有効にしたときだけ止まる表示は、どれも免除しない。既定の表示で閾値を超えて閃光すればFail。[独自: 動きを減らす設定の扱い。規範に例外がなく、適合要件5ですべての内容に適用し、G15が警告の見落としを書くため。根拠: 2.3.1-E01, E05]
- 広告・埋め込み動画・適合の対象外とした部分の閃光もFailにする。[根拠: 2.3.1-E01]

## 判断例

- **Pass:** 通知のバッジが1秒に1回点滅する。回数だけで決まる（点滅として2.2.2を別に確かめる）。[根拠: 2.3.1-E02]
- **Pass:** 1秒に5回点滅する、100×100 CSS px（10,000 CSS px）のアイコン。ほかに同時の点滅はない。[根拠: 2.3.1-E03]
- **Fail:** ページの背景全体が白と黒で1秒に5回切り替わるCSSアニメーション。白（相対輝度1.0）と黒（0.0）の差は10%を大きく超え、暗い側も0.80未満。[根拠: 2.3.1-E02–E04]
- **Fail:** 全画面で再生できる動画の爆発の場面で、画面の大部分が1秒に4回、白と暗い赤に切り替わる。再生ボタンを押した後でも免除しない。[根拠: 2.3.1-E01, E04]
- **要確認:** 夜景の動画で、画面の大部分が1秒に4回わずかに明るくなる。2コマの相対輝度の差が10%前後で、圧縮で値がぶれる。解析ツールで確かめる。[独自: 検査例。根拠: 2.3.1-E04, E05]

## 作るとき

- 点滅させるなら、どの1秒間でも3回以下にする。[根拠: 2.3.1-E02]
- 3回を超える点滅が要るなら、点滅する面積を小さくし、明暗の差を小さくする。[根拠: 2.3.1-E03, E04]
- 動画は公開前に解析ツールで確かめ、超える場面は編集する。警告だけで済ませない。[根拠: 2.3.1-E05]

## 確かめるとき

- **自動で確定する範囲:** なし。`auto-play-detection` の差分は動くものの候補で、閃光の回数・面積・明暗は決めない。[根拠: 2.3.1-E02–E04]
- **確定:** 1秒間の切り替わりの回数、同時に点滅する面積、明暗の色を確かめた結果。動画は再生した時刻と場面を証跡に残す。[根拠: 2.3.1-E02–E04]
- **残る:** 監査で再生しなかった動画の場面、ログイン後や操作の後にだけ出る内容。再生した範囲を報告に書く。[独自: 検査範囲]
- **言い切らない:** 動画を静止画1枚で判定しない。止める手段や警告があることをPassの根拠にしない。[根拠: 2.3.1-E01, E05]
