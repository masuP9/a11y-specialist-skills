# 1.2.5 音声解説（収録済み）

- 対象: 同期したメディアに含まれる収録済み映像
- 要る材料: 映像と主音声、解説を含む音声・別版、静的説明、解説を挿入できる間、プレイヤーの動作
- 自動チェック: trackや別版リンクは候補。主音声・解説・映像の内容を再生して照合する
- 原文確認日: 2026-11-02。WCAGは2024-12-12勧告、Understanding / Techniquesは随時更新の公開ページ。以下は引用ではなく要約。

## 根拠

### 1.2.5-E01 — AAの音声経路と同期したメディアの範囲を確認する

- **種別・出典:** [規範 — Audio Description (Prerecorded)](https://www.w3.org/TR/2024/REC-WCAG22-20241212/#audio-description-prerecorded)、[規範 — synchronized media](https://www.w3.org/TR/2024/REC-WCAG22-20241212/#dfn-synchronized-media)、[Understanding — Intent](https://www.w3.org/WAI/WCAG22/Understanding/audio-description-prerecorded.html#intent)。
- **要約:** 主音声で伝わらない重要な視覚情報を音声解説で伝える。既に主音声が充足していれば追加は不要。テキストの代替と明示されたメディアはsynchronized mediaの定義から除かれる。
- **適用条件・限界:** 本基準の文言に1.2.3と同じ例外句がないことだけで、用語の除外を無視しない。一方、近くにテキストがあるだけでは除外しない。通常の動画で全文テキストだけを用意しても、1.2.3の達成を本基準の達成へ移せない。

### 1.2.5-E02 — 別トラック以外の音声解説も認める

- **種別・出典:** [Technique — G78「Description / Tests」](https://www.w3.org/WAI/WCAG22/Techniques/general/G78#description)（Sufficient）、[G173「Description / Tests」](https://www.w3.org/WAI/WCAG22/Techniques/general/G173#description)（具体的な実装技術を用いてSufficient）、[G226「Description」](https://www.w3.org/WAI/WCAG22/Techniques/general/G226#description)（G173と併用してSufficient）。
- **要約:** 解説入りの選択音声・既定音声・別版の動画、制作時に組み込むナレーションなどを利用できる。必要な動作・画面内文字・結果を音声で伝え、重要な元の音声を覆わない。
- **適用条件・限界:** 別版へ実際に到達して再生できるか確認する。追加のtrack要素や特定のボタンを必須にしない。

### 1.2.5-E03 — 話者1人の静的な動画ではG203を照合する

- **種別・出典:** [Technique — G203「Description / Tests」](https://www.w3.org/WAI/WCAG22/Techniques/general/G203#description)（1.2.3・1.2.5にSufficient）。
- **要約:** 背景が変わらず話者1人が話すなど、重要な時間依存の視覚情報がない場合、音声で伝わらない話者名・環境・冒頭末尾のクレジット等を、プログラムで関連付けた静的テキストで伝えられる。
- **適用条件・限界:** 複数話者が入れ替わり、誰かを映像だけで示す場合には使わない。スライド・実演等の重要な変化がある動画を「話している動画」という理由だけで含めない。`aria-describedby` は一例であり唯一の関連付け方法ではない。

### 1.2.5-E04 — 利用できる間と拡張音声解説を分ける

- **種別・出典:** [Failure — F113「Description / Tests」](https://www.w3.org/WAI/WCAG22/Techniques/failures/F113#description)、[規範 — Extended Audio Description (Prerecorded)](https://www.w3.org/TR/2024/REC-WCAG22-20241212/#extended-audio-description-prerecorded)。
- **要約:** 重要な視覚情報が伝わらず、解説に適した間が残っていればF113の条件を確認する。短すぎる間、該当場面から離れた間、重要な音を妨げる間を一律に利用可能としない。停止して解説を加える拡張音声解説はAAAの1.2.7で扱う。
- **適用条件・限界:** F113の「2秒未満」等は例示であり固定閾値ではない。F113が成立しないことだけでSC全体の適合を証明しない。通常の間で対応できる不足と、拡張しないと伝えられない不足を区別して報告する。

### 1.2.5-E05 — descriptionsのtrackの存在と音声提供を分ける

- **種別・出典:** [Technique — H96「Description」](https://www.w3.org/WAI/WCAG22/Techniques/html/H96#description)（Advisory）。
- **要約:** descriptionsは読み上げ用の時間付きテキスト。実際に非視覚的に提示され、必要な解説を聞けるかを確認する。
- **適用条件・限界:** H96の2023年9月時点のネイティブ対応に関する注記を、現在の全ブラウザの検証結果として扱わない。対象環境のプレイヤー・補助実装で再生し、読み上げの欠落・打切りを確認する。属性検査だけで本基準の適合にしない。

## 線引き

- 主音声で重要な視覚情報がすべて伝わる通常例は適合。別の音声解説がないだけで指摘しない。解説付きの音声・別版が必要情報を伝える場合も適合。[根拠: 1.2.5-E01–E02]
- テキストの代替と明示され、その情報を超えないメディアは対象外。元のテキストとの対応と表示を確認する。[根拠: 1.2.5-E01]
- G203の条件を満たす場合は、関連付けた静的説明で適合とする。映像だけで話者や手順が変わる場合はこの経路へ入れない。[根拠: 1.2.5-E03]
- 主音声・解説・G203のいずれでも重要な視覚情報が伝わらず、解説に使える間が残っていれば不適合。間と解説の利用状況が未取得なら、その場面の音声・映像を追加確認する。[根拠: 1.2.5-E01–E04]
- 通常の音声解説に使える間を確認し使い切っており、残る不足を伝えるには映像の停止による拡張が必要な場合、その不足だけでAAのFailにしない。AAの確認範囲と残る情報を記録し、AAAの1.2.7として分ける。「会話が多い」だけでこの扱いにしない。[独自: AAAの拡張要件をAAへ混ぜない報告方針。根拠: 1.2.5-E04]
- DOMにtrackがあっても、対象環境で解説を聞けず他の経路も成立しないなら提供済みとしない。未再生なら要確認。[根拠: 1.2.5-E02・E05]

## 判断例

- **適合:** 操作を行うたび、主音声が対象の名前・操作・表示結果を説明している。追加トラックは不要。[根拠: 1.2.5-E01–E02]
- **適合:** 背景の変わらない話者1人の挨拶動画で、音声にない氏名・肩書・クレジットを関連付けた説明で読める。重要な時間依存の視覚情報はない。[根拠: 1.2.5-E03]
- **対象外:** 元の説明文の代替と明示された動画が、その説明文の情報だけを伝える。[根拠: 1.2.5-E01]
- **不適合:** 画面だけに出る重要な操作手順があり、適した発話の間もあるが音声では説明されない。全文テキストがあって1.2.3に適合しても、本基準の代用にはならない。[根拠: 1.2.5-E01・E04]
- **AAではその不足を指摘しない:** 利用できる間は解説に使い、残る細部には停止して説明する時間が必要。残る情報と拡張の必要性を記録し、AAAの確認へ分ける。[独自: 上記の報告方針の適用例。根拠: 1.2.5-E04]
- **要確認:** descriptionsのtrackだけが見つかり、読み上げは未確認。プレイヤーを操作し、聞ける内容と映像を照合する。[独自: 検査例。根拠: 1.2.5-E05]

## 作るとき

- 制作時から重要な視覚情報をナレーションへ組み込む。追加する場合は、元の音声を妨げず、解説を選択・再生できる経路を用意する。[根拠: 1.2.5-E02]
- G203は対象条件を確認して使い、track方式は対象環境で聞けることまで確かめる。[根拠: 1.2.5-E03・E05]

## 確かめるとき

- **確定:** 主音声・音声解説・静的説明の内容と対象条件を照合した結果。F113を使う場合は利用できる間も記録する。[根拠: 1.2.5-E01–E05]
- **残る:** 映像だけの情報、利用可能な間、別版への到達と再生、合成音声の打切り。
- **言い切らない:** track欠落だけでFail、track存在だけでPassにしない。再生時刻・不足する情報・間の状況を記録し、1.2.3のテキスト経路とAAAの1.2.7を混同しない。[根拠: 1.2.5-E01–E05。証跡形式は独自]
