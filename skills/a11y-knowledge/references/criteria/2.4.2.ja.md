# 2.4.2 ページタイトル

- 対象: ページ全体
- 要る材料: `<title>`（`page-snapshot` の `details.title`）、見出し（主題を読み取る）、複数ページならタイトルの一覧
- 自動チェック: axe の `document-title`

## 根拠

- [Understanding 2.4.2](https://www.w3.org/WAI/WCAG22/Understanding/page-titled.html)（[日本語](https://waic.jp/translations/WCAG22/Understanding/page-titled.html)）
  - タイトルは「主題または目的を説明する」こと。要件はそれだけ。
  - 解説書は、ページごとに違うタイトルや「ページ名 - サイト名」の形を望ましいとしているが、要件ではない。
  - 利用者がタブの一覧や履歴からページを見分けられることが意図。
- [G88: 説明的なタイトル](https://www.w3.org/WAI/WCAG22/Techniques/general/G88)、[H25: title 要素](https://www.w3.org/WAI/WCAG22/Techniques/html/H25)、[F25: 主題を表さないタイトル](https://www.w3.org/WAI/WCAG22/Techniques/failures/F25)

## 線引き

- 判断の軸は「タイトルがページの主題または目的を表しているか」。ほかのページと違うことは求めない。[解説書]
- サイト名だけ・「無題」のような既定の文字・ファイル名や URL で、見出しから分かる主題がタイトルに無ければ不適合。トップページのように主題がサイトそのものなら、サイト名だけでも適合。[解説書]（F25）
- タイトルが、見出しから分かる主題とは別の主題・目的を表していれば不適合（見出しが「ごみの分別と出し方」で、タイトルが「お問い合わせ」）。見出しから主題が分かるのに「目的を表しているのかもしれない」として要確認にしない。[独自]（誤判定の型から）
- サイト名の有無・並び順・区切り・長さは問わない。[解説書]
- タイトルがほかのページと同じことだけでは不適合にしない。中身の違うページに同じタイトルが続くのは、主題を表していない強い手がかりだが、検索結果のページ送りや、同じ中身を別の URL で出すページは重なってよい。[解説書]
- `<title>` が無い・空は不適合に確定（axe の `document-title`）。[解説書]

## 作るとき

- `<title>` に、そのページの主題（h1 と同じでよい）を入れる。「ページ名 | サイト名」の形が分かりやすい。
- SPA で画面が変わるときは `document.title` も変える。
- 一覧のページ送りは「検索結果（2 ページ目）」のように、続きであることが分かる形にする。
- トップページはサイト名だけでよい。

## 確かめるとき

- **確定**: axe の `document-title` の違反（無い・空）は不適合。pass は適合に数えない。
- **残る**: タイトルと見出しを見比べ、主題を表しているかを決める。複数ページなら同じタイトルの組を見比べる（[cross-page](../cross-page.ja.md)）。
- **言い切らない**: 同じタイトルが続くことだけで不適合にしない。サイト名が無いことを不適合にしない。
