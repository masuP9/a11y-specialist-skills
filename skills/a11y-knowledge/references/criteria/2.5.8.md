# 2.5.8 Target Size (Minimum)

- Components in scope: button, link, checkbox, radio, switch, combobox, slider, tab, menuitem, option
- Inputs needed: measurement (target-size-check from `@a11y-skills/audit`), whether it is in running text (the surrounding tree)
- Automated checks: target-size-check, axe `target-size` (when the WCAG 2.2 tag is enabled)

## Rationale

- [Understanding 2.5.8](https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum.html) ([Japanese translation](https://waic.jp/translations/WCAG22/Understanding/target-size-minimum.html))
  - 24 × 24 CSS px or more. Exceptions: spacing (a 24px circle does not overlap neighboring targets), another target with the same function, links in running text (within a sentence or within text constrained by line height), the user agent's default presentation, a particular presentation is essential.
  - The "inline" exception covers things within the flow of text, like a link inside a paragraph. Navigation or lists made up only of links are not inline.
- [C42: minimum size](https://www.w3.org/WAI/WCAG22/Techniques/css/C42), [F113: under 24px with no spacing](https://www.w3.org/WAI/WCAG22/Techniques/failures/F113)

## Judgment lines

- Targets under 24px that do not fall under an exception are non-conformant. Decided by measurement. [Understanding]
- Judgment is needed only for targets under 24px that the measurement marked as "candidate for the inline exception". Confirm from the surrounding tree or name whether it is a link in running text (inside a paragraph, within text constrained by line height). Conformant unless there is grounds to deny it, such as a link inside a paragraph. [Understanding]
- Where only links are lined up, as in navigation or lists, the inline exception does not apply. Non-conformant if the 24px circle overlaps a nearby target (there are `intersections`); needs review if it does not. [Understanding]
- A pass on axe `target-size` may be counted as conformant. [Our interpretation]

## When building

- Make buttons, icons, and checkboxes 24 × 24px or more. If making them look small, widen the pressable area with padding.
- For small links lined up (pagination, social media icons), space them out or make them larger.
- Links in running text are an exception, so they may stay at line height.

## When checking

- **Settled**: violations of target-size-check (under 24px and not under an exception) are non-conformant.
- **Remains**: whether candidates with `exception: "inline"` are really in running text.
- **Do not assert**: do not mark conformant without measurement.
