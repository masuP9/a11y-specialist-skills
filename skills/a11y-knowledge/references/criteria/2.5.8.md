# 2.5.8 Target Size (Minimum)

- Components: pointer-operated controls (button, link, checkbox, slider, and others)
- Evidence needed: measurements of the actionable area and its surroundings, context, equivalent controls, and display states
- Automated checks: target-size-check, axe `target-size`
- Sources checked: 2026-11-01. WCAG: Recommendation of 2024-12-12; Understanding / Techniques: WCAG 2.2 published pages (updated in place). The following are summaries, not quotations.

## Rationale

### 2.5.8-E01 — Undersized does not by itself mean failure

- **Type / source:** [Normative — WCAG 2.2 “Target Size (Minimum)”](https://www.w3.org/TR/2024/REC-WCAG22-20241212/#target-size-minimum), exceptions and notes.
- **Summary:** Undersized targets have exceptions for spacing, an equivalent control on the same page, inline content, unmodified user-agent sizing, and essential presentation.
- **Conditions / limits:** An assumed exception does not establish conformance. A tool finding no exception does not rule them all out. Do not divide a position-based input area, such as a slider, into separate small targets for every value.

### 2.5.8-E02 — Check spacing against both circles and targets

- **Type / source:** [Technique — C42 “Tests”](https://www.w3.org/WAI/WCAG22/Techniques/css/C42#tests) (Sufficient).
- **Summary:** Center a 24 CSS pixel diameter circle on the undersized target's bounding box. Check intersections with other targets and circles of other undersized targets.
- **Conditions / limits:** Exclude targets covered by other exceptions when applying the test. C42 provides spacing through placement inside containers; a 24px container is not necessarily a 24px actionable area. This CSS technique is not mandatory.

### 2.5.8-E03 — The inline exception depends on context

- **Type / source:** [Understanding — “Exceptions”](https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum.html#exceptions).
- **Summary:** The exception covers targets in a sentence or whose size is constrained by the line-height of non-target text.
- **Conditions / limits:** `display: inline`, a parent tag, or a link name alone is insufficient evidence. Navigation consisting solely of links is not exempt merely because it uses inline display.

### 2.5.8-E04 — Distinguish a bounding rectangle from the actionable area

- **Type / source:** [Understanding — “Size requirement”](https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum.html#size-requirement).
- **Summary:** Check whether a page-axis-aligned 24 × 24 CSS pixel square fits within the actionable area. When an overlay appears, distinguish obscured targets behind it from newly displayed controls.
- **Conditions / limits:** Bounding rectangles alone cannot settle non-rectangular or clipped targets. Testing the initial display does not cover controls inside opened menus or dialogs.

## Judgment lines

- Mark a target non-conformant when undersizing and the absence of every applicable exception have been confirmed. Inadequate spacing does not imply failure if another exception applies. [Evidence: 2.5.8-E01, 2.5.8-E02]
- Leave uncertain inline context as needs review. The absence of contrary evidence does not establish the inline exception. [Evidence: 2.5.8-E03]
- A target meeting the spacing conditions can be judged under that exception. Do not return it to needs review just because it is small; retain review if neighboring targets may have escaped detection. [Evidence: 2.5.8-E01, 2.5.8-E02]
- Record the measured targets, shapes, and states. Do not extend a target-level result to the whole page. [Our interpretation: recording coverage. Evidence: 2.5.8-E04]

## Judgment examples

- Apply the inline exception to a prose link such as “terms of use” in “See the terms of use for details”; do not require 24px sizing or spacing from adjacent links. Distinguish navigation consisting only of links. [Evidence: 2.5.8-E03. Our application example]
- Treat dense map pins that must retain their accurate locations as essential because their position and spacing convey information. Zoom buttons do not convey those locations and are not included in this exception. The UA calendar of an input type="date" whose size the author has not modified also qualifies for an exception. [Evidence: 2.5.8-E01, 2.5.8-E03]

## When building

- Enlarge the actionable area with padding or similar means. Enlarging only the visible icon or an outer container is insufficient. [2.5.8-E02, 2.5.8-E04]
- Space small links to satisfy the circle checks. Use the inline exception after checking context. [2.5.8-E02, 2.5.8-E03]

## When checking

- **Settled:** Judge targets after checking size, spacing, and exceptions. [2.5.8-E01–E04]
- **Remaining:** `target-size-check` results with `exceptionAssessment: "possible"` / `"not-assessed"` need review. `"verified"` confirms spacing within the detected set; it does not cover missed neighbors, iframes, shadow DOM, non-rectangular areas, or other display states. [Our interpretation: tool mapping. Implementation: [runTargetSizeCheck.ts](../../../../packages/a11y-audit/src/playwright/runTargetSizeCheck.ts), [types.ts](../../../../packages/a11y-audit/src/types.ts)]
- **Do not assert:** `intersections` is evidence against the spacing exception, not against other exceptions. An axe pass also cannot establish criterion-wide conformance beyond its measurement and detection scope. [2.5.8-E01, 2.5.8-E04]
