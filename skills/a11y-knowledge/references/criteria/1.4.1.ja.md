# 1.4.1 色の使用

- 対象: ページ全体（色で情報を伝えている箇所を探す）。部品には付かない
- 要る材料: ページ全体の画像（色以外の手がかりが見えるか）、要素のスタイル（太さ・サイズ・下線・枠線・明るさ）
- 自動チェック: axe の `link-in-text-block`（文中のリンク）

## 根拠

- [Understanding 1.4.1](https://www.w3.org/WAI/WCAG22/Understanding/use-of-color.html)（[日本語](https://waic.jp/translations/WCAG22/Understanding/use-of-color.html)）
  - 色を使うことは禁じていない。色「だけ」で情報・動作・応答・見分けを伝えないこと。
  - 相対輝度の差（明るさの差）は「色以外の区別」に当たる。Understanding の注: 色相が違っても明るさの比が 3:1 以上あれば、色の見分けに頼っていない。
  - コントラスト比そのものは 1.4.3 / 1.4.11 の範囲。
- [G14: 色以外の手がかり](https://www.w3.org/WAI/WCAG22/Techniques/general/G14)、[G182: 色の違いを明るさの差でも示す](https://www.w3.org/WAI/WCAG22/Techniques/general/G182)、[G183: 3:1 のコントラストと追加の手がかり](https://www.w3.org/WAI/WCAG22/Techniques/general/G183)、[F13: 画像の色だけで伝える](https://www.w3.org/WAI/WCAG22/Techniques/failures/F13)、[F73: 文中リンクを色だけで示す](https://www.w3.org/WAI/WCAG22/Techniques/failures/F73)、[F81: エラーを色だけで示す](https://www.w3.org/WAI/WCAG22/Techniques/failures/F81)

## 線引き

- 探すのは、色の違いで情報を伝えている箇所: グラフの系列と凡例、必須や入力の誤りを赤字・赤枠で示すもの、選択中・現在地を色で示すナビやタブ、状態を色の点やバッジで示すもの、「赤字の項目は〜」のように色で説明する注記。[解説書]
- 色以外の手がかり（文字・記号・形・模様・線の種類・下線・太字・枠・アイコンの形・位置）で同じ情報が分かれば適合。手がかりは画面に見えているものに限る。アクセシビリティツリーにだけある文字（見えない文字、`aria-current`）は見た目の手がかりにならない。[解説書]
- 項目ごとに色が違っても、その項目に見えている名前や文字が同じ情報を伝えていれば挙げない（Info / Success / Warning / Error のように、種類ごとに色を分けて名前も書いたボタン。色は名前の補い）。[独自]（誤判定の型から）
- 選択中・現在地として挙げるのは、同じ見た目の項目が並ぶ中で 1 つ（または一部）だけ色が違うときに限る。全部の色が違う並びから選択中を推測しない。`aria-pressed` / `aria-selected` / `aria-current` は手がかりに数えないが、選択の状態を持つ部品かを見分ける材料にする。[独自]
- 明るさの差: どれが他と違うかが分かれば足りるもの（選択中・現在地、1 つだけ違う項目）は、前景と背景の入れ替えや、白と濃い色のように明るさの比が 3:1 以上あれば適合。明るさが近い色（同じくらいの明るさの赤と緑）や差が際どいものは不適合。[解説書]（Understanding の注）
- 「赤は必須、青は任意」「緑の点はオンライン、赤の点はオフライン」のように、その色が何色かを知らないと意味が分からないものは、明るさの差があっても不適合。[独自]（明るさの差は「どれが違うか」にしか効かない）
- 手がかりの意味がページの離れた場所で説明されていても、その説明が見えていれば手がかりとして数える（「* は入力必須です」の注記と、離れた所の「住所 *」）。[独自]
- 同じ見た目（赤枠・赤字）の欄や項目が並ぶときは、1 つずつ手がかりを確かめる。エラーの文や記号は、それが付いている欄の手がかりにしかならない（隣の欄にだけエラーの文があれば、文の無い欄は不適合）。[独自]（見逃しの型から）
- 「赤字の項目は入力必須です」のように色だけで説明する注記は、注記そのものと、その色を使う項目の両方を不適合にする。[解説書]
- グラフは、系列と凡例が色だけで対応していれば不適合。線の種類・マーカーの形・系列に直接付いた名前・すぐそばの同じ値の表があれば適合。[解説書]（G111 / G14）
- 挙げないもの: 文中のリンクを色だけで見分けている箇所（axe の `link-in-text-block` に任せる）、意味を持たない色（見出しの背景、ブランドの色、飾り）、色そのものを伝える色見本、写真やイラストの中の色、コントラスト比（1.4.3 / 1.4.11）、ホバーやフォーカスで初めて変わる色。[独自]（分担）
- スタイルで確かめるときに手がかりに数える差: `font-weight` の差が 200 以上（400→600。100 の差は見分けにくい）、`font-style` の違い、文字サイズの比が 1.125 倍以上、`text-decoration-line` の違い、枠線の見えている辺の太さの違い、背景または文字色の明るさの比が 3:1 以上。枠線の色だけの違いは数えない。[独自]

## 作るとき

- 色で状態・区分を示すところには、必ずもう 1 つの手がかりを付ける: 必須は「*」や「必須」の文字、エラーは文とアイコン、選択中は太字・下線・枠、グラフの系列は線種・マーカー・直接のラベル。
- 「赤字は必須」のような注記を書かない。色の代わりに記号や文字で示し、その意味を注記する。
- 文中のリンクは下線を残す。色だけで見分けさせない。
- 明るさの差で区別するなら 3:1 以上にし、「どれが違うか」にだけ使う。色の意味（赤＝危険）を明るさで代替しない。

## 確かめるとき

- **確定**: axe の `link-in-text-block` の違反は不適合（文中リンクの色だけの区別）。
- **残る**: 上の線引きに当たる箇所を、ページ全体の画像を見て探す。色だけに見える箇所は、スタイル（太さ・下線・枠線・明るさ）で手がかりの有無を確かめ直す。
- **言い切らない**: 名前や文字が同じ情報を伝えている色分けを不適合にしない。コントラスト比の問題を 1.4.1 にしない。ホバーで変わる色を画像から判定しない。
