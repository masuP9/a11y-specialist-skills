# 3.1.1 ページの言語

- 対象: ページ全体
- 要る材料: `html` の lang（`page-snapshot` の `details.lang`）、本文の言語（snapshot の先頭の文字）
- 自動チェック: axe の `html-has-lang`、`html-lang-valid`

## 根拠

- [Understanding 3.1.1](https://www.w3.org/WAI/WCAG22/Understanding/language-of-page.html)（[日本語](https://waic.jp/translations/WCAG22/Understanding/language-of-page.html)）
  - ページの「既定の言語」（主な言語）がプログラムで判断できること。HTML では `html` の `lang`。
  - 複数の言語が同じくらい使われていれば、最初に使われる言語か、最も多い言語を既定にする。
  - 一部だけ別の言語なのは 3.1.2 の範囲。
- [H57: html の lang 属性](https://www.w3.org/WAI/WCAG22/Techniques/html/H57)

## 線引き

- 判断の軸は「html の lang の主な言語（ハイフンの前）が、本文の主な言語と同じか」。[解説書]
- lang が無い・空・書き方が不正なものは不適合に確定（axe）。そのページでは本文との照合はしない。[解説書]
- 地域や文字の部分（`ja-JP` の `JP`）の違いは問わない。[独自]
- 複数の言語が混ざるページは、いちばん多い言語で決める。一部だけ別の言語なのは 3.1.2 の範囲なので理由にしない。本文の言語を決められなければ要確認。[解説書]
- axe の `html-has-lang` の pass は適合に数えない。lang があることと、本文と合っていることは別。[独自]
- 限界: 本文の先頭だけで判断すると、ナビゲーションだけ別の言語のページで本文の言語を取り違えうる。[独自]

## 作るとき

- `<html lang="ja">` を必ず書く。テンプレートに固定で入れる。
- 多言語サイトは、ページごとの言語に合わせて lang を切り替える（英語ページで `lang="ja"` のままにしない）。
- 一部だけ別の言語（引用、固有名詞以外の英文）には、その要素に lang を付ける（3.1.2）。

## 確かめるとき

- **確定**: axe の `html-has-lang` / `html-lang-valid` の違反は不適合。
- **残る**: lang と本文の言語が合っているか。本文の先頭だけでなく、主な内容を見る。
- **言い切らない**: `html-has-lang` の pass を適合にしない。一部の別言語を 3.1.1 の不適合にしない。
