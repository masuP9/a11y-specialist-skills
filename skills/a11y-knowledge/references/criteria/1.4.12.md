# 1.4.12 Text Spacing

- Scope: Text in markup supporting the applicable spacing properties
- Needed: Applied overrides, retained content/functionality, full-text access, language/script and layouts
- Automated checks: text-spacing-check (new/worsened hidden/clip overflow)

- Sources checked: 2026-11-01. WCAG: 2024-12-12 Recommendation; Understanding / Techniques: live WCAG 2.2 pages. Summaries, not quotations.

## Rationale

### 1.4.12-E01 — Evaluate overrides, not default appearance

- **Type / source:** [Normative — WCAG 2.2, Text Spacing](https://www.w3.org/TR/2024/REC-WCAG22-20241212/#text-spacing), [Understanding — Author Responsibility / User Responsibility](https://www.w3.org/WAI/WCAG22/Understanding/text-spacing#intent).
- **Summary:** Apply all four relevant properties together without changing other styles. Neither default author values nor a site-provided settings UI are required.
- **Conditions / limits:** Test line height 1.5, paragraph spacing 2 times font size, letter spacing 0.12em, and word spacing 0.16em. A malfunctioning override method alone does not establish author failure absent deliberate prevention. Distinguish breakage only at excessive settings.

### 1.4.12-E02 — Distinguish truncation with full-text access

- **Type / source:** [Understanding — Use of ellipses](https://www.w3.org/WAI/WCAG22/Understanding/text-spacing#use-of-ellipses), [Failure — F104, Tests](https://www.w3.org/WAI/WCAG22/Techniques/failures/F104#tests).
- **Summary:** Check clipping/overlap that makes content unavailable. Ellipsized text may remain available on focus, activation, or a linked page.
- **Conditions / limits:** Geometric overflow alone does not establish F104. Verify full-text access and distinguish unrecoverable clipping.

### 1.4.12-E03 — Wrapping is not mandatory; test each layout

- **Type / source:** [Technique — C35, Description / Tests](https://www.w3.org/WAI/WCAG22/Techniques/css/C35#tests), [C36, Description / Tests](https://www.w3.org/WAI/WCAG22/Techniques/css/C36#tests) (both Sufficient).
- **Summary:** Non-wrapping short strings can accommodate spacing through spare room or growing containers. Test each responsive layout.
- **Conditions / limits:** nowrap or fixed dimensions alone do not establish failure. One default view does not cover other layouts.

### 1.4.12-E04 — Check language/script applicability

- **Type / source:** [Normative — Exception](https://www.w3.org/TR/2024/REC-WCAG22-20241212/#text-spacing), [Understanding — Applicability](https://www.w3.org/WAI/WCAG22/Understanding/text-spacing#applicability).
- **Summary:** Assess only properties used by the language/script combination. Distinguish images of text and burned-in video text from text subject to overrides.
- **Conditions / limits:** A language name alone does not exempt the whole criterion. Check applicable properties for mixed text and individual regions.

## Judgment lines

- Fail after verifying loss from appropriate overrides that full-text access or other mechanisms cannot recover. [Evidence: 1.4.12-E01, 1.4.12-E02]
- Retain the existing operational pass for the inspected scope when nothing is detected, provided appropriate overrides actually applied. Do not extend it to unmeasured layouts/states. This measurement alone does not prove absence of overlap or full-text availability. [Our interpretation: author policy; limits: 1.4.12-E01–E04]
- Detected `clippedElements` alone do not establish failure. The tool also adds bottom margins to non-paragraph div/span elements; check whether extraneous changes caused the issue and whether full text remains accessible. Distinguish CLI classification from WCAG judgment. [Our interpretation: tool mapping; implementation: [constants.ts](../../../../packages/a11y-audit/src/constants.ts), [runTextSpacingCheck.ts](../../../../packages/a11y-audit/src/playwright/runTextSpacingCheck.ts)]

## When building

- Allow containers to grow and avoid losses from fixed heights or nowrap/overflow combinations. Recommend unitless line-height and widths allowing wrapping. [Our interpretation: author recommendation; supporting evidence: 1.4.12-E02, 1.4.12-E03]

## When checking

- **Conclusive:** Lost content/functionality with override conditions and full-text access verified. [1.4.12-E01, 1.4.12-E02]
- **Remaining:** Visual overlap, unapplied overrides, untested targets such as input fields, alternate layouts, and opened/closed states. Uncertain applicable properties need review. [Our interpretation: tool scope; supporting evidence: 1.4.12-E03, 1.4.12-E04]
- **Do not overclaim:** Do not pass without measurement or require these values in the default design. [Our interpretation: measurement policy; evidence: 1.4.12-E01]
