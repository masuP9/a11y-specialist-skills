# 1.4.12 Text Spacing

- Scope: whole page
- Inputs needed: measurement (text-spacing-check from `@a11y-skills/audit`)
- Automated checks: text-spacing-check

## Rationale

- [Understanding 1.4.12](https://www.w3.org/WAI/WCAG22/Understanding/text-spacing.html) ([Japanese translation](https://waic.jp/translations/WCAG22/Understanding/text-spacing.html))
  - Content and functionality must not be lost when the user sets line height to 1.5, paragraph spacing to 2 times, letter spacing to 0.12em, and word spacing to 0.16em.
  - The author is not obliged to use those spacings. The requirement is that nothing breaks when the user changes them.
  - Examples of loss: text clipped, overlapping, or hidden.
- [C36: no clipping when spacing is changed](https://www.w3.org/WAI/WCAG22/Techniques/css/C36), [F104: clipping or overlapping when spacing is changed](https://www.w3.org/WAI/WCAG22/Techniques/failures/F104)

## Judgment lines

- If there is an element whose text is clipped or overlaps when spacing is changed, non-conformant. [Understanding] (F104)
- Zero clipped elements may be marked conformant, but add that the measurement does not check text overlap. [Our interpretation]

## When building

- Do not fix line height or box height. Do not write `line-height` in `px`, and let boxes grow with their content.
- Do not trap button or navigation text with a combination of `white-space: nowrap` and `overflow: hidden`.
- Avoid fixed widths so text can wrap even when letter spacing is widened.

## When checking

- **Settled**: text-spacing-check `issueCount > 0` (there are clipped elements) is non-conformant.
- **Remains**: visual overlap when the count is zero. Check places of concern visually.
- **Do not assert**: do not mark conformant without measurement.
