# 1.4.12 テキストの間隔

- 対象: ページ全体
- 要る材料: 実測（`@a11y-skills/audit` の text-spacing-check）
- 自動チェック: text-spacing-check

## 根拠

- [Understanding 1.4.12](https://www.w3.org/WAI/WCAG22/Understanding/text-spacing.html)（[日本語](https://waic.jp/translations/WCAG22/Understanding/text-spacing.html)）
  - 行間 1.5、段落間 2 倍、字間 0.12em、単語間 0.16em を利用者が設定しても、内容や機能が失われないこと。
  - 作者がその間隔にする義務は無い。利用者が変えたときに壊れないことが要件。
  - 文字が切れる・重なる・隠れる、が失われる例。
- [C36: 間隔を変えても切れない](https://www.w3.org/WAI/WCAG22/Techniques/css/C36)、[F104: 間隔を変えると切れる・重なる](https://www.w3.org/WAI/WCAG22/Techniques/failures/F104)

## 線引き

- 間隔を変えたときに文字が切れる・重なる要素があれば不適合。[解説書]（F104）
- 切れる要素が 0 件なら適合にしてよいが、実測は文字の重なりまでは見ていないと書き添える。[独自]

## 作るとき

- 行の高さ・箱の高さを固定しない。`line-height` を `px` で書かず、箱は中身に合わせて伸びるようにする。
- ボタンやナビの文字を `white-space: nowrap` と `overflow: hidden` の組み合わせで閉じ込めない。
- 字間を広げても折り返せるように、幅の固定を避ける。

## 確かめるとき

- **確定**: text-spacing-check の `issueCount > 0`（切れる要素がある）は不適合。
- **残る**: 0 件のときの見た目の重なり。気になる箇所は目視で見る。
- **言い切らない**: 実測が無い状態で適合にしない。
