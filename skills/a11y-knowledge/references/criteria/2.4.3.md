# 2.4.3 Focus Order

- Scope: whole page (not attached per component)
- Inputs needed: measurement (`tabOrder` from focus-indicator-check and focus-order-check in `@a11y-skills/audit`). The Tab order and position of each element
- Automated checks: focus-order-check, axe `tabindex` (positive values)

## Rationale

- [Understanding 2.4.3](https://www.w3.org/WAI/WCAG22/Understanding/focus-order.html) ([Japanese translation](https://waic.jp/translations/WCAG22/Understanding/focus-order.html))
  - The requirement is "an order that preserves meaning and operability", not "an order that matches the visual order". Even if different from the visual order, conformant if the meaning holds.
  - Some content has no single correct order (multiple valid orders).
  - Moving focus into a dialog when it opens and back when it closes is also within the range of 2.4.3.
- [G59: matching source order to visual order](https://www.w3.org/WAI/WCAG22/Techniques/general/G59), [F44: an order that harms meaning via tabindex](https://www.w3.org/WAI/WCAG22/Techniques/failures/F44), [F85: not moving focus into a dialog](https://www.w3.org/WAI/WCAG22/Techniques/failures/F85)

## Judgment lines

- Compare the order of Tab movement with the reading order (top to bottom, left to right). Non-conformant if a movement that greatly deviates from reading order (jumping from the middle of the body text to the bottom of the page and back) can be read as harming meaning or operation. [Understanding]
- Conformant if there is no deviation, the measurement finished to the end, no elements were skipped, and there is at least one operable element. If it cannot be judged, needs review. [Our interpretation]
- Fixed-position (fixed / sticky) elements (a header, a banner stuck to the bottom) have positions that depend on scrolling. Do not mark a move to or from an element that can be read as fixed-position from its name or selector non-conformant solely because of a positional deviation. [Our interpretation]
- A positive `tabindex` tends to break the order, but do not mark non-conformant on that alone (decide by the resulting order). [Understanding]
- Do not mark conformant when the measurement stopped partway, skipped elements, or truncated the order (cut off at the limit). [Our interpretation]

## When building

- Match the DOM order to the visual order. Do not reorder only visually with CSS `order` or `flex-direction: row-reverse`.
- Do not use positive numbers for `tabindex`.
- Move focus inside a dialog when it opens, and back to the button that opened it when it closes.
- Make elements not shown on screen (inside a closed menu) unfocusable (`inert`, `display: none`).

## When checking

- **Settled**: none.
- **Remains**: read the order and positions in `tabOrder` and decide whether a deviation harms meaning or operation.
- **Do not assert**: do not mark non-conformant solely because the order differs from the visual order. Do not mark conformant from a measurement that stopped partway.
