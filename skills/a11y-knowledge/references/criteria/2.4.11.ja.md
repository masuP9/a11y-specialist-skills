# 2.4.11 隠されないフォーカス（最低限）

- 対象: ページ全体
- 要る材料: 実測（`@a11y-skills/audit` の focus-indicator-check の `obscured`。固定表示の要素との重なり）
- 自動チェック: focus-indicator-check（`focus-not-obscured`）

## 根拠

- [Understanding 2.4.11](https://www.w3.org/WAI/WCAG22/Understanding/focus-not-obscured-minimum.html)（[日本語](https://waic.jp/translations/WCAG22/Understanding/focus-not-obscured-minimum.html)）
  - フォーカスした要素が、作者の作った内容（固定ヘッダー、貼り付くフッター、クッキーバナー）に完全に隠れないこと。一部が見えていれば最低限は満たす（完全に見えることは 2.4.12 の AAA）。
  - 利用者が開いたもの（メニュー、ダイアログ）で隠れるのは例外。利用者が動かせる（閉じられる）内容で隠れるのも例外。
- [C43: スクロールマージンで隠れないようにする](https://www.w3.org/WAI/WCAG22/Techniques/css/C43)、[F110: 固定要素に隠れる](https://www.w3.org/WAI/WCAG22/Techniques/failures/F110)

## 線引き

- フォーカスした要素が固定表示（fixed / sticky）の要素に完全に隠れた（99% 以上）とき、重ねているのが利用者が開いたもの（メニュー・ダイアログ）と読み取れなければ不適合。[解説書]
- 一部だけ隠れたものは 2.4.11 では適合（2.4.12 の範囲）。[解説書]
- 完全に隠れた要素が 0 件で、実測が最後まで終わり、操作できる要素が 1 つ以上、飛ばした要素が 0 件なら適合。「固定表示の要素との重なりだけを調べた」と書き添える。[独自]
- 完全に隠れた要素が無いのに不適合にしない。実測が途中で止まっても、見つかった不適合は残す。[独自]

## 作るとき

- 固定ヘッダー・フッターがあるなら、`scroll-padding-top` / `scroll-padding-bottom`（または要素の `scroll-margin`）で、フォーカスした要素が固定部分の下に入らないようにする。
- クッキーバナーは画面の一部にとどめ、フォーカスで隠れる範囲を小さくする。
- 貼り付くバナーは閉じられるようにする（利用者が動かせるなら例外になる）。

## 確かめるとき

- **確定**: `fullyObscured` の要素があり、重ねているのが固定表示の内容なら不適合。
- **残る**: 重ねているのが利用者が開いたものかを見る。
- **言い切らない**: 一部だけ隠れた要素を 2.4.11 の不適合にしない。途中で止まった実測で適合にしない。
