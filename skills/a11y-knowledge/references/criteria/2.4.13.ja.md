# 2.4.13 フォーカスの外観

- 対象: AAAを評価する場合の、キーボードフォーカス表示
- 要る材料: 非フォーカス時の部品・下位部品の形状、同じ位置の前後の色、条件を満たす表示面積、UA表示の変更有無
- 自動チェック: 現行focus-indicator-checkのスタイル差分・画像差分だけでは、この基準を判定できない

- 原文確認日: 2026-11-01。WCAGは2024-12-12勧告、Understanding / Techniquesは随時更新のWCAG 2.2公開ページ。以下は引用ではなく要約。

## 根拠

### 2.4.13-E01 — 太さの宣言だけでなく有効面積を見る

- **種別・出典:** [規範 — WCAG 2.2「Focus Appearance」](https://www.w3.org/TR/2024/REC-WCAG22-20241212/#focus-appearance)、[Understanding —「Minimum area」](https://www.w3.org/WAI/WCAG22/Understanding/focus-appearance.html#minimum-area)。
- **要約:** 非フォーカス時の部品・下位部品の2 CSS px周囲相当の面積と、同じ位置の前後で3:1以上の差を両方満たす表示領域を評価する。形状はoutlineに限らない。
- **適用条件・限界:** 奥に入り込んだ2px線は面積不足になりうる。「2辺ある」「outline-width: 2px」だけで適合にしない。影や発光を部品の外形に足さない。

### 2.4.13-E02 — 隣接色とのコントラストだけでは足りない

- **種別・出典:** [Understanding —「Relationship with Non-text Contrast」](https://www.w3.org/WAI/WCAG22/Understanding/focus-appearance.html#relationship-with-non-text-contrast)。
- **要約:** 1.4.11は表示と隣接色、2.4.13はフォーカス前後の同じ位置を比較する。片方だけを満たす表示がある。
- **適用条件・限界:** 比較した状態・位置と、3:1を満たす面積を記録する。単なる画像差分量は、この条件を満たす面積ではない。

### 2.4.13-E03 — UA表示の例外は背景も確認する

- **種別・出典:** [規範 — 同基準のExceptions](https://www.w3.org/TR/2024/REC-WCAG22-20241212/#focus-appearance)、[Understanding —「Exceptions」](https://www.w3.org/WAI/WCAG22/Understanding/focus-appearance.html#exceptions)。
- **要約:** UAが決め作者が調整できない表示、または作者が表示とその背景色を変更していない場合を区別する。
- **適用条件・限界:** 「outlineは変更していない」だけで後者の例外にしない。背景色の変更も確認する。1.4.11の例外と同じ条件と決めつけない。

### 2.4.13-E04 — 二色の表示も成立条件を確認する

- **種別・出典:** [Technique — C40「Description」「Tests」](https://www.w3.org/WAI/WCAG22/Techniques/css/C40#tests)（Sufficient）。
- **要約:** C40は二色間9:1以上、各帯2 CSS px以上、部品の外側で単一の均一背景上にあることを確認する。一方の帯だけでも面積と色差を確保できる構成。
- **適用条件・限界:** 「白黒の二色だから適合」と一般化しない。画像・グラデーション・別部品にまたがる場合は個別に測る。box-shadowだけに頼る場合は強制カラーモードで消える可能性も確認する。

## 線引き

- 例外を確認し、適用対象では面積と前後の色差を両方確かめる。全周や2辺の独自推奨を、このAAA基準の適合条件に置き換えない。[根拠: 2.4.13-E01–E04]
- AAの監査では追加の改善候補として扱い、AAAの不適合をAAの不適合にしない。2.4.7・1.4.11はそれぞれ評価する。[独自: 報告範囲の管理。参考根拠: 2.4.13-E02]

## 作るとき

- 部品自身の識別できる表示という[2.4.7の独自推奨](./2.4.7.ja.md)を維持する。AAAを目指す場合は、前後の色差を満たす面積にも余裕を持たせる。[独自: 実装方針。参考根拠: 2.4.13-E01]
- C40を使う場合は背景の条件と各帯を確認し、outlineとbox-shadowの役割を保つ。[2.4.13-E04]

## 確かめるとき

- **確定:** 例外に該当せず、有効面積または前後の色差が不足すると確認できた場合に不適合。[2.4.13-E01, 2.4.13-E03]
- **残る:** 部品・下位部品の外形、複雑な背景、UA表示の変更範囲。計測できなければ要確認。[2.4.13-E01–E04]
- **言い切らない:** `visualDiff`やスタイル変更の検出を、面積・3:1の検証とみなさない。[独自: ツールとの対応。実装: [axe-format.ts](../../../../packages/a11y-audit/src/utils/axe-format.ts)]
