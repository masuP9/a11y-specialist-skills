# 2.5.1 Pointer Gestures

- Scope: whole page
- Inputs needed: measurement (pointer-gesture-check from `@a11y-skills/audit`. Candidates listed from event listeners and markup)
- Automated checks: pointer-gesture-check

## Rationale

- [Understanding 2.5.1](https://www.w3.org/WAI/WCAG22/Understanding/pointer-gestures.html) ([Japanese translation](https://waic.jp/translations/WCAG22/Understanding/pointer-gestures.html))
  - Functionality operated by multiple fingers (pinch) or path-based gestures (swipe, drawing) needs a means to do the same thing with a single pointer (tap, click).
  - The exception is when the gesture is essential (a handwritten signature).
  - Providing a gesture is not itself a problem. The absence of an alternative is the problem.
- [G215: the same thing can be done with a single pointer](https://www.w3.org/WAI/WCAG22/Techniques/general/G215), [G216: a single pointer is all that is needed](https://www.w3.org/WAI/WCAG22/Techniques/general/G216), [F105: gesture only](https://www.w3.org/WAI/WCAG22/Techniques/failures/F105)

## Judgment lines

- Measurement only goes as far as listing, with the page open, candidates for "elements that seem to be operated by multiple fingers or paths" from event listeners and markup. No events are sent. [Our interpretation]
- One or more candidates is needs review; zero is not applicable. Whether there is a single-pointer means or whether the gesture is essential has not been confirmed, so neither conformant nor non-conformant is marked. [Our interpretation]
- Candidates often do not attach to an element (a carousel container and so on). Attach the verdict per page and list the candidates as the reason. [Our interpretation]
- Limitations: inside iframes, listeners added after a press, and operations built with delegation are not found. [Our interpretation]

## When building

- Give carousels switched by swipe previous and next buttons.
- Give maps zoomed by pinch + / − buttons.
- Do not build path-based functionality except for drawing and signatures.

## When checking

- **Settled**: none.
- **Remains**: for each candidate, actually try whether the same thing can be done with a single pointer.
- **Do not assert**: do not mark conformant or not applicable while there are candidates. Do not mark non-conformant from candidates alone.
