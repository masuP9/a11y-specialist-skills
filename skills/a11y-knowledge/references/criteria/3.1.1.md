# 3.1.1 Language of Page

- Scope: whole page
- Inputs needed: lang on `html` (`details.lang` from `page-snapshot`), the language of the body text (the first characters of the snapshot)
- Automated checks: axe `html-has-lang`, `html-lang-valid`

## Rationale

- [Understanding 3.1.1](https://www.w3.org/WAI/WCAG22/Understanding/language-of-page.html) ([Japanese translation](https://waic.jp/translations/WCAG22/Understanding/language-of-page.html))
  - The page's "default language" (primary language) must be programmatically determinable. In HTML, this is `lang` on `html`.
  - If several languages are used about equally, make the default the language used first or the language used most.
  - Parts in a different language are the range of 3.1.2.
- [H57: the lang attribute on html](https://www.w3.org/WAI/WCAG22/Techniques/html/H57)

## Judgment lines

- The axis of judgment is "is the primary language of the html lang (before the hyphen) the same as the primary language of the body text". [Understanding]
- A missing, empty, or malformed lang is settled as non-conformant (axe). On that page, no comparison with the body text is made. [Understanding]
- Differences in the region or script part (the `JP` in `ja-JP`) are not asked. [Our interpretation]
- For pages mixing several languages, decide by the language used most. Parts in a different language are the range of 3.1.2, so do not use them as a reason. If the language of the body text cannot be determined, needs review. [Understanding]
- A pass on axe `html-has-lang` is not counted as conformant. Having a lang and matching the body text are different things. [Our interpretation]
- Limitation: judging only from the beginning of the body text can misidentify the body language on a page where only the navigation is in a different language. [Our interpretation]

## When building

- Always write `<html lang="ja">`. Put it in the template permanently.
- On multilingual sites, switch lang to match each page's language (do not leave `lang="ja"` on an English page).
- For parts in a different language (quotations, English sentences other than proper nouns), put lang on that element (3.1.2).

## When checking

- **Settled**: violations of axe `html-has-lang` / `html-lang-valid` are non-conformant.
- **Remains**: whether the lang matches the language of the body text. Look at the main content, not only the beginning of the body text.
- **Do not assert**: do not mark a pass on `html-has-lang` conformant. Do not mark parts in a different language non-conformant under 3.1.1.
