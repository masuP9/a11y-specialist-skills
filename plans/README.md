## Findings considered and rejected

Recorded so the next audit run doesn't re-litigate them:

- **Path traversal in output paths** (`src/utils/test-harness.ts`): by-design —
  a local audit tool writing where its operator points it; `outputFile` is
  already validated to a bare basename.
- **URL scheme validation before `page.goto`**: by-design — the target URL is
  operator-supplied; the audited page is untrusted by definition and runs in a
  Playwright-isolated context.
- **Runtime perf of checks** (serial `ariaSnapshot` in target-size, repeated
  `getComputedStyle`/`querySelectorAll('*')` in focus check): real but not
  worth doing — saves at most low seconds per audit run on large pages; revisit
  only if users report runtime pain.

  clearer than a generator; duplication cost is near zero.

  no observable impact (fresh context per run; assertions guarded by prior
  length checks).
